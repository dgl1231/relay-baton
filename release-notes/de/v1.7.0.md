# v1.7.0 — Modell wählen, zwischen Modellen wechseln

relay-baton kann jetzt wählen, **welches Modell** jede Agent-CLI nutzt, und den Staffelstab zwischen Modellen desselben Agents weitergeben – nicht nur zwischen Agents.

## Änderungen

- **`--model <id>`** für `run`, `plan`, `execute` und `handoff`, weitergereicht an das Modell-Flag der CLI (`codex exec -m`, `claude --model`, `gemini -m`, …). Jede ID funktioniert, neue Modelle brauchen kein Update.
- Standardmodell pro Agent in der Config: `agents.<id>.model`. Fehlt es, gilt wie bisher der CLI-Standard.
- **Fallback zwischen Modellen desselben Agents**: `--chain claude:claude-opus-5-5,claude:claude-sonnet-5,codex`.
- **Modellauswahl in der Desktop-App** neben dem Codex/Claude-Schalter: Vorschläge aktueller Modelle oder freie Eingabe. Leer = CLI-Standard.
- Erweiterte Fallback-Erkennung: `overloaded_error`, `resource_exhausted`, `credit balance is too low`, `context window exceeded`.
- `session.json` speichert `activeModel` / `reportedModel`.

## Kompatibilität

- Rein additiv. Ohne `--model` sind die Befehle identisch zu v1.6.x.
