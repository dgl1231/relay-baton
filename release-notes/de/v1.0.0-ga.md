# v1.0.0 — Allgemeine Verfügbarkeit (GA)

Erstes öffentliches, allgemein verfügbares Release (GA). relay-baton verlässt die
dauerhafte `-alpha.N`-Linie. Keine Funktionsänderungen gegenüber der letzten
Alpha; dieses Release macht das Projekt **rechtlich nutzbar und installierbar**.

> Dies ist die **GA**-Notiz zum Tag `v1.0.0`. Die frühere
> [`v1.0.0.md`](../v1.0.0.md) dokumentiert den Pre-GA-Meilenstein „Stable Local
> Release“ und bleibt zur Historie erhalten.

## Hinzugefügt

- **MIT `LICENSE`** im Repo-Root (zuvor ohne Lizenz = „all rights reserved“).
  `license: "MIT"` in jedem Paket-Manifest.
- **npm-Distribution** — das CLI erscheint als **`@relay-baton/cli`** (installiert
  den bekannten `relay-baton`-Befehl), dazu die öffentlichen Bibliotheken
  `@relay-baton/core`·`shared`·`tui`. `npm i -g @relay-baton/cli` /
  `npx @relay-baton/cli` funktionieren ohne Klonen.
- **Paketmanager** — Homebrew-Tap (`dgl1231/homebrew-relay-baton`), Scoop-Bucket
  (`dgl1231/scoop-relay-baton`) und Winget (`dgl1231.relay-baton`).
- **`CHANGELOG.md`** + eine Release-Pipeline, die mit einem Tag an alle Kanäle
  (npm/Homebrew/Scoop/Winget) verteilt.

## Geändert

- Alle Pakete auf Version **1.0.0**; GA-Versionierung ersetzt `-alpha.N`.

## Harte Vorgaben (unverändert, per Test gesichert)

- Keine direkten OpenAI/Anthropic-API-Aufrufe; nur Subprocess über die lokalen
  CLIs `codex`/`claude`. Kein Speichern/Ausgeben von API-Keys. Kein automatisches
  commit/push/PR; kein Daemon; nur deterministische Kompaktierung.
