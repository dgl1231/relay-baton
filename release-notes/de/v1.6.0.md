# v1.6.0 — Moderner Windows-Installer

Die Windows-Desktop-App wird jetzt als **markengestalteter NSIS-Installer**
statt des klassischen MSI-Assistenten ausgeliefert.

## Was sich ändert

- **`…-setup.exe` (NSIS), nicht `…_en-US.msi`.** Ein moderner Installer mit
  einem warm-dunklen Willkommenspanel passend zur App — die gedrehte orange
  Raute, der `relay-baton`-Schriftzug und der Slogan `codex → claude handoff`.
- **Installation pro Benutzer, keine UAC-Abfrage.** Installiert in dein
  Benutzerprofil wie VS Code oder Discord — kein „Zulassen, dass diese App
  Änderungen vornimmt"-Dialog, keine Administratorrechte.

## Upgrade von einer MSI-Installation

Der NSIS-Build ist ein anderer Installer-Typ. Wenn du eine frühere Version
über das MSI installiert hast, deinstalliere sie einmal über **Einstellungen →
Apps** (oder die alte Verknüpfung „Uninstall relay-baton") und führe dann das
neue `…-setup.exe` aus. Künftige Updates bleiben beim NSIS-Installer.

## Nicht betroffen

- **CLI-Nutzer** (npm / Homebrew / Scoop / Winget) — unverändert. Diese Kanäle
  installieren das eigenständige `relay-baton`-Binary, unabhängig vom
  Desktop-Installer.
- macOS `.dmg` und Linux `.AppImage` — unverändert.
- Keine CLI- oder App-Verhaltensänderungen; Versionen im Lockstep.
