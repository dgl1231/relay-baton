# v1.2.0 — Relevo más inteligente & UI amigable

> Nota: los nombres de etiqueta v1.1.x se usaron en la línea «Distributable» anterior a GA, así que la primera versión de funciones tras GA sale como v1.2.0.

Primera versión de funciones tras GA, con v2.8 «Smarter relay» y mejoras de experiencia en CLI/escritorio. Restricciones fuertes intactas: local-first, determinista, solo subprocess, confirmation-first, sin demonio.

## Añadido

- **Disparadores de handoff ampliados (opt-in).** Nuevo bloque opcional `handoffTriggers` (`budgetRatio` / `changedFiles` / `usageTokensProxy`): permite *sugerir* pasar el relevo aunque no se dispare ningún patrón de error de fallback. Al alcanzar el umbral pregunta y/N (o respeta `--yes`); sin configuración, la detección sigue siendo solo por patrón de error. Core: `HandoffTriggerPolicy`.
- **Disparador manual de handoff.** `relay-baton run --handoff-now` releva al siguiente agente tras cada salto sin esperar una señal de fallback (la propia bandera es el consentimiento explícito).
- **Sugerencias de enrutamiento (solo aviso).** Los agentes del registro llevan etiquetas de palabras clave `strengths`; `suggestChain` propone un orden de cadena y `run` imprime una sugerencia de una línea cuando difiere. Solo visualización — `--chain`/`--primary` explícitos siempre ganan.

## Mejorado

- **Salida de CLI amigable.** Nuevos ayudantes `ui` sin dependencias (✓ / ✗ / ▲ / → con pistas atenuadas de «qué probar a continuación»); salida de `run` con encabezados de salto y fallos de gate más claros. El color se desactiva automáticamente al canalizar o con `NO_COLOR`.
- **Reestilizado cálido del escritorio.** El webview de Tauri estrena paleta cálida (tema claro crema, tema oscuro cálido, acento terracota), tipografía sans para la interfaz, radios/sombras más suaves y eventos de conversación tipo tarjeta. Solo visualización — el webview sigue llamando únicamente al sidecar CLI.

## Corregido

- Los prompts de confirmación de `run` ya no se quedan colgados para siempre cuando stdin no es un TTY (CI/entrada canalizada): rechazan automáticamente con una pista para pasar `--yes`.
- CI de Windows: la comparación de rutas del test de worktree ahora expande rutas cortas 8.3.

## Compatibilidad

- Sin cambios incompatibles. La nueva clave `handoffTriggers` es opcional y se valida; los esquemas de artefactos no cambian.
