# v1.3.1 — Hotfix de escritorio

**Corrige que la app de escritorio no abriera en absoluto** en compilaciones sin
firmar (todos los MSI/DMG/AppImage desde que se introdujo el updater). El shell
de Rust registraba el plugin updater de Tauri incondicionalmente, pero el
pipeline solo inyecta la config `plugins.updater` cuando existen secretos de
firma — así que las compilaciones sin firmar entraban en pánico al arrancar
(exit 101) antes de mostrar ventana alguna.

Ahora el plugin updater solo se registra cuando su bloque de configuración está
presente. Sin cambios en el CLI — los usuarios de npm/Homebrew/Scoop/Winget no
se ven afectados.
