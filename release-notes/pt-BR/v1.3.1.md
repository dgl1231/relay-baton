# v1.3.1 — Hotfix do desktop

**Corrige o app desktop que não abria de jeito nenhum** em builds não assinados
(todos os MSI/DMG/AppImage desde a introdução do updater). O shell Rust
registrava o plugin updater do Tauri incondicionalmente, mas o pipeline só
injeta a config `plugins.updater` quando existem segredos de assinatura — então
builds não assinados entravam em pânico na inicialização (exit 101) antes de
mostrar qualquer janela.

O plugin updater agora só é registrado quando seu bloco de configuração está
presente. Sem mudanças no CLI — usuários de npm/Homebrew/Scoop/Winget não são
afetados.
