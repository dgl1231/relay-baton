# v1.6.0 — Instalador de Windows moderno

O app desktop de Windows agora é distribuído como um **instalador NSIS com a
marca** em vez do clássico assistente MSI.

## O que mudou

- **`…-setup.exe` (NSIS), não `…_en-US.msi`.** Um instalador moderno com um
  painel de boas-vindas escuro e quente combinando com o app — o losango
  laranja rotacionado, o logotipo `relay-baton` e o slogan `codex → claude
  handoff`.
- **Instalação por usuário, sem prompt de UAC.** Instala no seu perfil de
  usuário como VS Code ou Discord — sem a caixa "permitir que este app faça
  alterações", sem direitos de administrador.

## Atualizando de uma instalação MSI

O build NSIS é um tipo de instalador diferente. Se você instalou uma versão
anterior pelo MSI, desinstale-a uma vez em **Configurações → Aplicativos** (ou
no antigo atalho "Uninstall relay-baton") e então rode o novo `…-setup.exe`.
As próximas atualizações permanecem no instalador NSIS.

## Não afetado

- **Usuários de CLI** (npm / Homebrew / Scoop / Winget) — inalterado. Esses
  canais instalam o binário `relay-baton` independente, que não depende do
  instalador de desktop.
- `.dmg` do macOS e `.AppImage` do Linux — inalterados.
- Sem mudanças na CLI ou no comportamento do app; versões em lockstep.
