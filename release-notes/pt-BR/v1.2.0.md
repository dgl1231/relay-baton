# v1.2.0 — Revezamento mais inteligente & UI amigável

> Nota: os nomes de tag v1.1.x foram usados pela linha «Distributable» pré-GA, então a primeira versão de recursos pós-GA sai como v1.2.0.

Primeira versão de recursos pós-GA, com v2.8 «Smarter relay» e melhorias de experiência no CLI/desktop. Restrições rígidas intactas: local-first, determinístico, apenas subprocess, confirmation-first, sem daemon.

## Adicionado

- **Gatilhos de handoff ampliados (opt-in).** Novo bloco opcional `handoffTriggers` (`budgetRatio` / `changedFiles` / `usageTokensProxy`): permite *sugerir* passar o bastão mesmo sem disparar um padrão de erro de fallback. Ao atingir o limite, pergunta y/N (ou respeita `--yes`); sem configuração, a detecção continua apenas por padrão de erro. Core: `HandoffTriggerPolicy`.
- **Gatilho manual de handoff.** `relay-baton run --handoff-now` passa para o próximo agente após cada salto sem esperar um sinal de fallback (a própria flag é o consentimento explícito).
- **Dicas de roteamento (apenas aviso).** Os agentes do registro recebem etiquetas de palavras-chave `strengths`; `suggestChain` propõe uma ordem de cadeia e o `run` imprime uma dica de uma linha quando difere. Apenas exibição — `--chain`/`--primary` explícitos sempre vencem.

## Melhorado

- **Saída de CLI amigável.** Novos auxiliares `ui` sem dependências (✓ / ✗ / ▲ / → com dicas esmaecidas de «o que tentar a seguir»); saída do `run` com cabeçalhos de salto e falhas de gate mais claras. A cor é desativada automaticamente ao redirecionar ou com `NO_COLOR`.
- **Restilização quente do desktop.** O webview do Tauri ganha paleta quente (tema claro creme, tema escuro quente, destaque terracota), fonte sans para a interface, raios/sombras mais suaves e eventos de conversa em cartões. Apenas exibição — o webview ainda chama somente o sidecar do CLI.

## Corrigido

- Os prompts de confirmação do `run` não travam mais para sempre quando o stdin não é um TTY (CI/entrada redirecionada) — recusam automaticamente com uma dica para passar `--yes`.
- CI do Windows: a comparação de caminhos do teste de worktree agora expande caminhos curtos 8.3.

## Compatibilidade

- Sem mudanças incompatíveis. A nova chave `handoffTriggers` é opcional e validada; os esquemas de artefatos não mudam.
