# v1.0.0 — Disponibilidade geral (GA)

Primeiro lançamento público e de disponibilidade geral (GA). O relay-baton
formou-se da linha perpétua `-alpha.N`. Sem mudanças de recursos em relação à
última alpha; este lançamento torna o projeto **legalmente utilizável e
instalável**.

> Esta é a nota **GA** da tag `v1.0.0`. O anterior
> [`v1.0.0.md`](../v1.0.0.md) documenta o marco "Stable Local Release" anterior ao
> GA e é mantido por histórico.

## Adicionado

- **`LICENSE` MIT** na raiz do repositório (antes sem licença = "all rights
  reserved"). `license: "MIT"` em cada manifesto de pacote.
- **Distribuição npm** — o CLI é publicado como **`@relay-baton/cli`** (instala o
  familiar comando `relay-baton`), além das bibliotecas públicas
  `@relay-baton/core`·`shared`·`tui`. `npm i -g @relay-baton/cli` /
  `npx @relay-baton/cli` funcionam sem clonar.
- **Gerenciadores de pacotes** — tap do Homebrew (`dgl1231/homebrew-relay-baton`),
  bucket do Scoop (`dgl1231/scoop-relay-baton`) e Winget (`dgl1231.relay-baton`).
- **`CHANGELOG.md`** + um pipeline de lançamento que distribui para todos os
  canais (npm/Homebrew/Scoop/Winget) com uma única tag.

## Alterado

- Todos os pacotes na versão **1.0.0**; o versionamento GA substitui `-alpha.N`.

## Restrições rígidas (inalteradas, travadas por testes)

- Sem chamadas diretas à API da OpenAI/Anthropic; apenas subprocess via os CLIs
  locais `codex`/`claude`. Sem armazenar/imprimir API keys. Sem commit/push/PR
  automático; sem daemon; apenas compactação determinística.
