# v1.7.0 — Escolha o modelo, faça fallback entre modelos

O relay-baton agora escolhe **qual modelo** cada CLI de agente usa e passa o bastão entre modelos do mesmo agente, não só entre agentes.

## O que mudou

- **`--model <id>`** em `run`, `plan`, `execute` e `handoff`, repassado à flag de modelo da CLI (`codex exec -m`, `claude --model`, `gemini -m`, …). Qualquer id funciona; modelos novos não exigem atualização.
- Modelo padrão por agente na config: `agents.<id>.model`. Sem ele, o padrão da CLI, como antes.
- **Fallback entre modelos do mesmo agente**: `--chain claude:claude-opus-5-5,claude:claude-sonnet-5,codex`.
- **Seletor de modelo no app desktop**, ao lado da troca Codex/Claude: sugestões de modelos atuais ou qualquer id. Vazio = padrão da CLI.
- Detecção de fallback ampliada: `overloaded_error`, `resource_exhausted`, `credit balance is too low`, `context window exceeded`.
- `session.json` registra `activeModel` / `reportedModel`.

## Compatibilidade

- Só adiciona. Sem `--model`, os comandos são idênticos à v1.6.x.
