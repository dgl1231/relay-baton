# v1.3.1 — デスクトップ ホットフィックス

**未署名ビルドでデスクトップアプリがまったく起動しない問題を修正**(updater
導入以降のすべての MSI/DMG/AppImage)。Rust シェルが Tauri updater プラグインを
無条件に登録していた一方、リリースワークフローは updater 署名シークレットが
ある場合のみ `plugins.updater` 設定を注入するため、未署名ビルドはウィンドウを
出す前に起動時パニックしていた(exit 101)。

updater プラグインは設定ブロックが存在する場合のみ登録されるようになった。
署名ビルドは opt-in updater を維持し、未署名ビルドは updater なしで正常起動する。

CLI 変更なし — npm/Homebrew/Scoop/Winget ユーザーへの影響はない。
