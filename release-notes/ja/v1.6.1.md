# v1.6.1 — ワンクリック Windows インストール

v1.6.0 の NSIS インストーラのフォローアップ: Windows のインストールが
ウィザードを経ずに**ワンクリック**で完了するようになった。

## 変更点

- **ウィザードページを廃止。** ウェルカム画面と「インストール場所の選択」
  ステップがなくなった。`…-setup.exe` をダブルクリックすると既定の
  per-user の場所へそのままインストールされ、ブランドの完了画面が表示される
  — Discord や VS Code のように、枠が邪魔をしないモダンなインストール方式。
- ウォームダークのブランドアート(オレンジのダイヤモンド + `relay-baton`
  ワードマーク)は、完了画面とインストール進行ヘッダーに引き続き表示される。
- 引き続き **per-user、UAC プロンプトなし**(v1.6.0 から)。

## 内部

- カスタム NSIS テンプレート(`desktop/src-tauri/installer/installer.nsi`、
  Tauri 公式テンプレートベース・バージョン一致)が、テンプレートに元からある
  `Skip` フックでウェルカム/ディレクトリページをスキップする。アップグレード
  時には再インストール確認画面がそのまま表示される。

## 影響なし

- CLI チャンネル(npm / Homebrew / Scoop / Winget)、macOS `.dmg`、Linux
  `.AppImage` — 変更なし。CLI やアプリの挙動に変更なし。バージョンは
  lockstep でバンプ。
