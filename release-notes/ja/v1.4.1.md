# v1.4.1 — デスクトップタイムラインの磨き込み

v1.4.0 デスクトップアプリの実使用で見つかった Agent Room タイムラインの
QoL 修正 2 件。デスクトップ専用 — CLI の動作に変更なし。バージョンは
lockstep でバンプ。

## 結果カードがタイムラインの再読み込みを生き延びる

v1.4.0 では、スラッシュコマンドの結果カードが次のコマンドのタイムライン
再読み込みと同時に消え、常に最新のカードしか見えなかった(以前からの挙動
だが、結果がカードになって格段に目立つようになった)。ローカルの結果カード
をメモリに保持し、再読み込みのたびにタイムスタンプ順でタイムラインへ再
マージするようにした — コマンドを連続で打っても読めるヒストリーが残る。
プロジェクト切り替え時にはクリアし(前のプロジェクトの話なので)、直近
50 件まで保持する。

## 話者別に色分けされたタイムライン行

user と relay-baton のイベントが同じ背景・同じ枠線で描画され、会話が
混ざって見えた。行が話者ごとに色分けされるようになった:

- **user** — 青の左ボーダー + 明るめの背景、コマンドは monospace
- **relay-baton** — アンバーの左ボーダー
- **claude** / **codex** — それぞれの agent カラー(ヘッダーのトグルと同一)

ダーク/ライト両テーマ対応。
