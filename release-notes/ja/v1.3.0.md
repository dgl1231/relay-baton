# v1.3.0 — ルートプレビュー & 磨き込み

GA 後の磨き込みリリース: advisory ルーティングヒントが正式な読み取り専用コマンドになり、親しみやすい CLI 出力が `run` 以外にも広がり、v1.2.0 の機能が完全にドキュメント化され、録画可能なデモシナリオが同梱される。ハード制約は不変: ローカルファースト、決定論的、subprocess のみ、confirmation-first、デーモンなし。

## 追加

- **`relay-baton route "<task>" [--json]`** — advisory ルーティングヒントの読み取り専用プレビュー。`run` と同じ方法でチェーンを解決し(フラグ > work-item 割り当て > プロジェクト > config)、レジストリの `strengths` タグがこのタスクに対して順序をどう提案するかを、エージェントごとのマッチしたキーワードとともに表示する。エージェントは起動せず、セッション状態も書かない。
- **デモシナリオ** — `scripts/demo/demo.sh` + `scripts/demo/fake-agent.mjs`: fake エージェントで fallback → compact handoff → 再開の流れを決定論的に再現(実際の codex/claude は実行せず、quota も消費しない)。`asciinema rec -c "bash scripts/demo/demo.sh" demo.cast` で録画。

## 改善

- **親しみやすい出力を拡大** — v1.2.0 の `ui` スタイル(✓ / ✗ / ▲ と「次に何をすべきか」のヒント)が `doctor`、`init`、`status`、`login`、`handoff` にも適用。`doctor`/`login` は従来 ANSI をハードコードし `NO_COLOR`/非 TTY を無視していたが、正しくプレーンテキストに落ちるようになった。
- **`doctor` がトリガー状態を表示** — 任意設定 `handoffTriggers` が構成済みかを Core info 行で示し、v1.2.0 の機能を発見しやすくする。
- **ドキュメント完備** — `--handoff-now`、`handoffTriggers` 設定ブロック(例 JSON 付き)、ルーティングヒント、`route` が `docs/COMMANDS.md`(EN+KO)、ガイド(EN+KO)、README の設定セクションに記載された。

## 互換性

- 破壊的変更なし。config/アーティファクトのスキーマ変更なし。`route` は純粋な追加。
