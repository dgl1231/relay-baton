# v1.7.0 — モデル選択とモデル間フォールバック

各agent CLIが使う**モデル**を選べるようになり、agent間だけでなく同じagentのモデル間でもバトンを渡せます。

## 変更点

- `run` / `plan` / `execute` / `handoff` に **`--model <id>`**。agent CLIのモデルフラグ(`codex exec -m`、`claude --model`、`gemini -m` …)へ渡します。任意のidを指定でき、今後の新モデルも更新不要です。
- configでagentごとの既定モデル `agents.<id>.model`。未指定ならこれまで通りCLIの既定。
- **同一agent内のモデルフォールバック**: `--chain claude:claude-opus-5-5,claude:claude-sonnet-5,codex`。
- **デスクトップのモデル選択欄**(Codex/Claude切替の隣): 最新モデルの候補、または任意入力。空欄 = CLI既定。
- フォールバック検出を拡大: `overloaded_error`、`resource_exhausted`、`credit balance is too low`、`context window exceeded`。
- `session.json` に `activeModel` / `reportedModel` を記録。

## 互換性

- 追加のみ。`--model` 未指定なら v1.6.x と同一のコマンドです。
