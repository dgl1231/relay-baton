# v1.0.0 — 正式リリース (GA)

初の公開・正式リリース(GA)。relay-baton は永続的な `-alpha.N` ラインを卒業する。
直前の alpha からの機能変更はなく、本リリースはプロジェクトを **法的に利用可能かつ
インストール可能** にする。

> これは `v1.0.0` タグの **GA** ノート。以前の
> [`v1.0.0.md`](../v1.0.0.md) は GA 前の「Stable Local Release」マイルストーンの
> 記録で、履歴として残している。

## 追加

- リポジトリ直下に **MIT `LICENSE`**(以前は未ライセンス=「all rights reserved」)。
  各パッケージ manifest に `license: "MIT"`。
- **npm 配布** — CLI は **`@relay-baton/cli`** として配布(おなじみの `relay-baton`
  コマンドを導入)、加えて公開ライブラリ `@relay-baton/core`・`shared`・`tui`。
  clone 不要で `npm i -g @relay-baton/cli` / `npx @relay-baton/cli` が動く。
- **パッケージマネージャ** — Homebrew tap(`dgl1231/homebrew-relay-baton`)、Scoop
  bucket(`dgl1231/scoop-relay-baton`)、Winget(`dgl1231.relay-baton`)。
- **`CHANGELOG.md`** + タグ 1 つで全チャネル(npm/Homebrew/Scoop/Winget)へ自動配信
  するリリースパイプライン。

## 変更

- 全パッケージを **1.0.0** に。GA バージョニングが `-alpha.N` を置き換える。

## ハード制約(不変、テストで固定)

- OpenAI/Anthropic API を直接呼ばない。ローカル `codex`/`claude` CLI の subprocess
  のみ。API キーの保存/出力なし。自動 commit/push/PR なし。デーモンなし。決定論的
  圧縮のみ。
