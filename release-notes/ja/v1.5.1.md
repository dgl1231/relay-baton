# v1.5.1 — 正直な実行終了 & 静かになったライブ出力

v1.5.0「デスクトップアプリから agent を実行」への小さなフォローアップ 2 件。
どちらも実機で実際の `/run` を検証中に見つかった。

## 失敗した終了を区別できるように

relay chain が**実行されたが非ゼロで終了した** agent で終わっても、
`run`(と `execute`)は依然として `0` で終了していた。デスクトップアプリでは
ストリーミング出力が `✗ <agent> exited with code N` で終わっても実行カードに
緑の `完了` チップが表示された。これらの終了は今後 **`4`** で終了するので、
実行カードはチップを赤で表示し、スクリプトも失敗終了と正常終了を区別できる。

`run`/`execute` の終了コード一覧: `0` 成功 · `1` agent を spawn できない ·
`2` 使用方法の誤り · `3` quality gate が handoff をブロック · `4` チェーンが
失敗した agent で終了。

## 静かになったライブ実行カード

Claude はターンの途中で通常の `rate_limit_event` テレメトリ行を出力する。
これは認識されるイベントではないため、これまではライブカードへ raw のまま
通過していた。今後は表示から抑制する(raw 行は引き続き fallback 検知と
ディスクログに届く — 情報の欠落なし)。

## 互換性

- 新しいコマンドやフラグはなし。外部から見える変更は終了コード `4` のみ。
- デスクトップと CLI のバージョンは lockstep でバンプ。
