# v1.2.0 — よりスマートなリレー & 親しみやすい UI

> 注記: v1.1.x のタグ名は GA 前の「Distributable」ラインで使われたため、GA 後の最初の機能リリースは v1.2.0 として出す。

GA 後の最初の機能リリースとして v2.8「Smarter relay」と CLI/デスクトップの UX 改善をまとめた。ハード制約は不変: ローカルファースト、決定論的、subprocess のみ、confirmation-first、デーモンなし。

## 追加

- **ハンドオフ トリガーの拡張(opt-in).** 新しい任意設定 `handoffTriggers`(`budgetRatio` / `changedFiles` / `usageTokensProxy`)により、fallback のエラーパターンが出ていなくてもバトンを渡すことを *提案* する。しきい値到達時は y/N 確認(または `--yes`)。設定が無ければ従来どおりエラーパターン検出のみ。Core: `HandoffTriggerPolicy`。
- **手動ハンドオフ トリガー.** `relay-baton run --handoff-now` は fallback シグナルを待たず各 hop 後に次のエージェントへリレーする(フラグ自体が明示的な同意)。
- **advisory ルーティング ヒント.** レジストリの各エージェントに `strengths` キーワードタグを追加。`suggestChain` がタスクに合うチェーン順を提案し、順序が異なるときだけ `run` が 1 行のヒントを表示する。表示のみ — 明示的な `--chain`/`--primary` が常に優先。

## 改善

- **親しみやすい CLI 出力.** 依存ゼロの `ui` ヘルパー(✓ / ✗ / ▲ / → と「次に何をすべきか」のヒント)。`run` の出力を hop 見出しと明確なゲート失敗表示に刷新。パイプ出力や `NO_COLOR` では色が自動で無効化される。
- **デスクトップの暖色リスタイル.** Tauri webview に暖色パレット(クリーム系ライト、暖色ダーク、テラコッタのアクセント)、UI にサンセリフ、柔らかな角丸/影、メッセージカード型の会話イベントを適用。表示のみ — webview は引き続き CLI sidecar のみを呼ぶ。

## 修正

- stdin が TTY でない(CI/パイプ)場合に `run` の確認プロンプトが無限に待機する問題を修正 — `--yes` を促すヒントを出して自動的に拒否する。
- Windows CI: worktree テストのパス比較が 8.3 短縮パスを展開するように修正。

## 互換性

- 破壊的変更なし。新しい設定キー `handoffTriggers` は任意で検証される。アーティファクトのスキーマ変更なし。
