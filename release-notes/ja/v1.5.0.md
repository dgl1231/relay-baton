# v1.5.0 — デスクトップアプリから agent を実行

Agent Room がビューアを卒業する: 実際に agent を起動できるようになった —
**確認後実行(confirmation-first)**、AGENT_ROOM 設計ドキュメントが当初から
定めていたとおり(preview → confirm → run)。クリックなしでは何も実行され
ない。

## `/run <task>` と「ここで実行」

- 新しい **`/run <task>`** composer コマンド:
  `relay-baton run "<task>" --primary <選択した agent> --pretty` を組み立てる
  — ヘッダーの Codex/Claude トグルが実際に誰が先に走るかを決めるようになった。
- **`/plan`、`/execute`、`/handoff`** も実際の起動コマンドを組み立てる
  (handoff は `--no-run` を削除)。
- いずれも既存の確認モーダルに**正確なコマンド**を表示し、新しい
  **「ここで実行」**ボタンがバンドルされた sidecar CLI で実行する(ローカル
  の agent ログイン/クォータを使用 — relay-baton は引き続きプロバイダ API を
  直接呼ばない)。ターミナルへのコピーも従来どおり。

## ライブ実行カード

agent の出力がタイムラインのライブカードへストリーミングされる(`--pretty`
形式): ツール呼び出し、assistant テキスト、締めのトークン/コスト領収書が
リアルタイムに現れる。**キャンセル**ボタンでプロセスを終了。終了時には
緑の `完了` または赤の `exit N` チップが付き、ダッシュボードパネルが更新
される。同時実行は 1 つ、出力は直近 400 行、カードは v1.4.1 の結果カードと
同様にタイムライン再読み込みを生き延びる。

## 内部 / 互換性

- Tauri capability の追加: sidecar スコープの `shell:allow-spawn` と
  キャンセル用の `shell:allow-kill`(execute のみではストリーミング実行が
  拒否されていた)。
- GUI は引き続きビジネスロジックなし: CLI を spawn して行を表示するだけ。
  すべてのゲート(handoff 品質、token diet、redaction、guardrail)は
  ターミナルと同じく CLI 内で動作する。
- ガイド/ツールチップ文言を GUI 全 4 言語で更新 — もはや read-only ではなく
  「確認後実行ダッシュボード」。
- CLI の動作に変更なし。バージョンは lockstep でバンプ。
