# v1.6.0 — モダンな Windows インストーラ

Windows デスクトップアプリが、従来の MSI ウィザードではなく**ブランド
デザインの NSIS インストーラ**として配布されるようになった。

## 変更点

- **`…_en-US.msi` → `…-setup.exe`(NSIS)。** アプリと統一されたウォーム
  ダークのウェルカムパネルを持つモダンなインストール画面 — 回転したオレンジ
  のダイヤモンドマーク、`relay-baton` ワードマーク、`codex → claude handoff`
  のタグライン。
- **per-user インストール、UAC プロンプトなし。** VS Code や Discord のように
  ユーザープロファイルへインストールされる —「このアプリに変更を許可します
  か」のダイアログも管理者権限も不要。

## MSI インストールからのアップグレード

NSIS ビルドは別のインストーラ形式です。以前のバージョンを MSI で
インストールしていた場合は、**設定 → アプリ**(または旧「Uninstall
relay-baton」ショートカット)から一度アンインストールし、新しい
`…-setup.exe` を実行してください。以後の更新は NSIS インストーラで続きます。

## 影響なし

- **CLI ユーザー**(npm / Homebrew / Scoop / Winget)— 変更なし。これらの
  チャンネルはデスクトップインストーラとは独立した `relay-baton` 単体バイナリ
  をインストールします。
- macOS `.dmg` と Linux `.AppImage` — 変更なし。
- CLI やアプリの挙動に変更なし。バージョンは lockstep でバンプ。
