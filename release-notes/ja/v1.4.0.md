# v1.4.0 — フレンドリーな agent ストリーム & デスクトップ結果カード

agent の出力がログのダンプではなく会話のように読めるようになった — CLI と
デスクトップアプリの両方で。

## `--pretty`: フレンドリーな agent ストリーム (CLI)

`run`、`plan`、`execute`、`handoff` にオプトインの `--pretty` フラグを追加。
agent CLI の機械可読イベントストリーム(`claude -p --output-format
stream-json --verbose`、`codex exec --json`)を要求し、読みやすい行として
レンダリングする:

```
● model claude-sonnet-5 · session abc123
  · thinking: need to look at the failing test first
→ Bash: pnpm test --filter core
Fixed the flaky test — two files changed.
✓ agent turn done — in 10,231 tok · out 1,892 tok · $0.0231 · 48.2s
```

- 決定的な JSONL 行単位パースのみ — モデル呼び出しや要約なし(Codex/Claude
  adapter の `parseEvent`)。
- パースできない行や構造化モードのない agent は raw のままパススルー。raw
  ストリーム全体は引き続き `.ai-session/commands.log` に残る。
- fallback 検知は従来どおり raw 行に対してマッチし続ける(JSON イベント内の
  エラーメッセージも含む)。
- 古い agent CLI がフラグ未対応の可能性があるためオプトイン。

## デスクトップ: Agent Room の構造化結果カード

スラッシュコマンドの結果(`/status`、`/budget`、`/git`、`/review`、
`/guard`、`/risk`、`/checkpoints`、`/sessions`、`/resume`、`/workspace`、
`/profile`、`/inventory`、`/inspect`、`/bundle`)が raw の
`JSON.stringify` ダンプではなく構造化カード(ステータスチップ、budget
ゲージバー、git のファイル別行、plan ステップのチェックリスト)として表示
される。各カードは折りたたまれた **raw json** セクションに元の payload を
そのまま保持する。すべて表示専用の DOM ビルダーで、webview にビジネス
ロジックは含まれない。

修正: `/review` の結果がレンダリング直後にタイムラインの再読み込みで消えて
いた問題。

## 互換性

- `--pretty` はオプトイン。デフォルト出力に変更なし。
- `AgentEvent` に新しいイベントタイプ(`system`、`assistant_text`、
  `reasoning`、`tool_use`、`usage`)を追加 — additive であり既存の利用側に
  影響なし。
- config / セッションスキーマの変更なし。
