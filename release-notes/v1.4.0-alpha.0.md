# v1.4.0-alpha.0 — Distribution polish

This alpha starts the v1.4 distribution hardening track. It keeps the existing
safety model intact: the desktop app remains sidecar-only and confirmation-first,
and release signing is optional so unsigned builds still work when secrets are
absent.

## What changed

- Added one-line CLI installers:
  - `install/install.sh` for macOS/Linux.
  - `install/install.ps1` for Windows.
- Installers fetch the latest release binary, verify it against `SHA256SUMS`,
  install without admin rights, and print PATH/next-step guidance.
- Added release finalization metadata:
  - `SHA256SUMS` over release assets.
  - best-effort CycloneDX SBOM (`relay-baton.cdx.json`).
- Added package-manager starter files:
  - `scoop/relay-baton.json`.
  - `homebrew/relay-baton.rb`.
- Wired optional signing hooks:
  - Windows MSI signing through Azure Artifact Signing when Azure signing
    secrets are present.
  - macOS signing/notarization environment variables passed through to Tauri
    builds when Apple Developer secrets are present.
- Added a desktop Codex/Claude target-agent switcher. It only affects previewed
  `/plan`, `/execute`, and `/handoff` commands; it does not launch an agent.

## Compatibility

- Existing manual downloads still work.
- Installers require `SHA256SUMS`, so they are intended for this release and
  newer.
- `scoop/` and `homebrew/` files currently target the latest known alpha and are
  intended to be hash-bumped on release.
- v1.3 stable promotion still requires real-window QA on a machine with Rust and
  the desktop runtime available.

## Safety

- No direct LLM API calls.
- No API-key storage.
- No auto commit, auto push, auto PR, daemon, or silent desktop updater.
- Desktop agent selection is display/pass-through only for previewed commands.
