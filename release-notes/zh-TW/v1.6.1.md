# v1.6.1 — 一鍵 Windows 安裝

v1.6.0 NSIS 安裝程式的跟進：Windows 安裝現在無需精靈，**一鍵**完成。

## 變更內容

- **移除精靈頁面。** 歡迎畫面和「選擇安裝位置」步驟都沒了。雙擊
  `…-setup.exe` 會直接安裝到預設的依使用者位置，並顯示品牌完成畫面 —— 更接近
  Discord、VS Code 等現代應用的安裝方式，讓框架不再擋路。
- 暖色深色品牌圖案（橘色菱形 + `relay-baton` 字標）仍出現在完成畫面和安裝
  進度標頭。
- 仍為 **依使用者安裝，無 UAC 提示**（自 v1.6.0 起）。

## 底層

- 自訂 NSIS 範本（`desktop/src-tauri/installer/installer.nsi`，基於 Tauri
  官方範本並版本相符）透過範本中既有的 `Skip` 掛鉤跳過歡迎/目錄頁面。升級時
  仍會顯示重新安裝確認畫面。

## 不受影響

- CLI 管道（npm / Homebrew / Scoop / Winget）、macOS `.dmg` 與 Linux
  `.AppImage` —— 不變。無 CLI 或應用行為變更；版本同步遞增。
