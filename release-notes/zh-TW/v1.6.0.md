# v1.6.0 — 現代化的 Windows 安裝程式

Windows 桌面應用現在以**品牌化的 NSIS 安裝程式**發佈，取代了經典的 MSI
精靈。

## 變更內容

- **`…_en-US.msi` → `…-setup.exe`（NSIS）。** 與應用統一的暖色深色歡迎面板
  的現代安裝畫面 —— 旋轉的橘色菱形標記、`relay-baton` 字標，以及
  `codex → claude handoff` 標語。
- **依使用者安裝，無 UAC 提示。** 像 VS Code 或 Discord 一樣安裝到你的使用者
  設定檔 —— 沒有「允許此應用進行變更」對話框，也不需要系統管理員權限。

## 從 MSI 安裝升級

NSIS 版本是不同的安裝類型。如果你之前用 MSI 安裝了舊版本，請先從**設定 →
應用程式**（或舊的「Uninstall relay-baton」捷徑）解除安裝一次，然後執行新的
`…-setup.exe`。之後的更新將繼續使用 NSIS 安裝程式。

## 不受影響

- **CLI 使用者**（npm / Homebrew / Scoop / Winget）—— 不變。這些管道安裝的是
  獨立於桌面安裝程式的 `relay-baton` 單檔二進位。
- macOS `.dmg` 與 Linux `.AppImage` —— 不變。
- 無 CLI 或應用行為變更；版本同步遞增。
