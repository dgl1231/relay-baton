# v1.5.0 — 在桌面應用中執行 agent

Agent Room 不再只是檢視器：現在它可以真正啟動 agent — **確認後執行
（confirmation-first）**，正如 AGENT_ROOM 設計文件從一開始就規定的那樣
（preview → confirm → run）。未經點擊，任何東西都不會執行。

## `/run <task>` 與「在此運行」

- 新的 **`/run <task>`** composer 指令：組出
  `relay-baton run "<task>" --primary <所選 agent> --pretty` — 頂部的
  Codex/Claude 切換現在真正決定誰先上場。
- **`/plan`、`/execute`、`/handoff`** 也會組出真實的啟動指令
  （handoff 移除了 `--no-run`）。
- 以上指令都會在既有確認視窗中顯示**精確指令**；新的**「在此運行」**按鈕
  透過打包的 sidecar CLI 執行（使用你本地的 agent 登入/配額 —
  relay-baton 仍然從不直接呼叫 provider API）。複製到終端的選項保留。

## 即時執行卡片

agent 輸出以即時卡片形式流入時間軸（`--pretty` 格式）：工具呼叫、
assistant 文字、結尾的 token/費用收據即時出現。**取消**按鈕可終止程序；
結束時卡片會帶上綠色 `完成` 或紅色 `exit N` 徽章，並重新整理儀表板面板。
同時只允許一個執行；輸出保留最近 400 行；卡片像 v1.4.1 的結果卡片一樣
在時間軸重載後保留。

## 底層 / 相容性

- Tauri capability 新增：sidecar 範圍的 `shell:allow-spawn` 與用於取消的
  `shell:allow-kill`（僅有 execute 會拒絕串流執行）。
- GUI 仍然不含業務邏輯：只是 spawn CLI 並顯示行。所有關卡（handoff 品質、
  token diet、redaction、guardrail）都和終端裡一樣在 CLI 內執行。
- 指南/提示文案在 GUI 全部 4 種語言中更新 — 應用現在是「確認後執行
  儀表板」，而非唯讀。
- CLI 行為不變；版本同步遞增。
