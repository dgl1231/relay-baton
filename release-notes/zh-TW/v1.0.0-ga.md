# v1.0.0 — 正式發佈 (GA)

首個公開的正式發佈(GA)。relay-baton 結束了長期的 `-alpha.N` 線。相較上一個 alpha
無功能變更;本次發佈讓專案 **在法律上可用且可安裝**。

> 這是 `v1.0.0` 標籤的 **GA** 說明。此前的
> [`v1.0.0.md`](../v1.0.0.md) 記錄的是 GA 之前的「Stable Local Release」里程碑,
> 保留作為歷史。

## 新增

- 儲存庫根目錄的 **MIT `LICENSE`**(此前無授權 = "all rights reserved")。
  每個套件 manifest 皆含 `license: "MIT"`。
- **npm 發佈** — CLI 以 **`@relay-baton/cli`** 發佈(安裝熟悉的 `relay-baton`
  指令),另有公開函式庫 `@relay-baton/core`·`shared`·`tui`。
  無需 clone 即可 `npm i -g @relay-baton/cli` / `npx @relay-baton/cli`。
- **套件管理器** — Homebrew tap(`dgl1231/homebrew-relay-baton`)、Scoop
  bucket(`dgl1231/scoop-relay-baton`)、Winget(`dgl1231.relay-baton`)。
- **`CHANGELOG.md`** + 一個標籤即可向全通路(npm/Homebrew/Scoop/Winget)自動散佈的
  發佈流水線。

## 變更

- 所有套件版本升至 **1.0.0**;GA 版本方案取代 `-alpha.N`。

## 硬性限制(不變,由測試鎖定)

- 不直接呼叫 OpenAI/Anthropic API;僅透過本地 `codex`/`claude` CLI subprocess。
  不儲存/列印 API key。無自動 commit/push/PR;無常駐程式;僅確定性壓縮。
