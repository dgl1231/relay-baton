# v1.5.1 — 誠實的執行結束 & 更安靜的即時輸出

對 v1.5.0「在桌面應用中執行 agent」的兩個小跟進，都是在實機驗證真實
`/run` 時發現的。

## 失敗結束現在可區分

當 relay chain 結束於一個**執行了但以非零退出**的 agent 時，`run`（與
`execute`）仍然以 `0` 退出。在桌面應用上，即便串流輸出以
`✗ <agent> exited with code N` 結尾，執行卡片也顯示綠色 `完成` 徽章。
現在這些結束會以 **`4`** 退出，因此執行卡片會把徽章標紅，指令稿也能區分
失敗結束與正常結束。

`run`/`execute` 完整退出碼：`0` 成功 · `1` 無法 spawn agent · `2` 用法錯誤
· `3` quality gate 阻擋了 handoff · `4` 鏈結束於失敗的 agent。

## 更安靜的即時執行卡片

Claude 會在回合中途輸出常規的 `rate_limit_event` 遙測行。它們不是已辨識
的事件，此前會以 raw 形式透傳到即時卡片。現在從顯示中抑制它們（raw 行仍
到達 fallback 偵測與磁碟日誌 —— 無資訊遺失）。

## 相容性

- 無新指令或旗標；唯一新增的外部行為是退出碼 `4`。
- 桌面與 CLI 版本同步遞增。
