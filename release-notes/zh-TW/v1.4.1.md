# v1.4.1 — 桌面端時間軸打磨

在實際使用 v1.4.0 桌面應用時發現的 Agent Room 時間軸體驗修正 2 項。僅桌面端
— CLI 行為無變化；版本號同步遞增。

## 結果卡片在時間軸重載後保留

在 v1.4.0 中，斜線指令的結果卡片會在下一條指令重載時間軸時立即消失——任何
時刻都只能看到最新一張卡片（這是既有行為，只是結果變成卡片後明顯得多）。
現在本地結果卡片保存在記憶體中，每次重載時按時間戳重新合併回時間軸——連續
執行指令也能留下可讀的歷史。切換專案時清空（卡片描述的是上一個專案），
最多保留最近 50 張。

## 依角色著色的時間軸行

user 與 relay-baton 的事件此前以相同背景、相同邊框呈現，對話混在一起難以
區分。現在行依發言者著色：

- **user** — 藍色左邊框 + 較亮的背景，指令以 monospace 顯示
- **relay-baton** — 琥珀色左邊框
- **claude** / **codex** — 各自的 agent 顏色（與頂部切換按鈕一致）

深色/淺色主題皆支援。
