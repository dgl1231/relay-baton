# v1.3.0 — 路由預覽 & 打磨

GA 後的打磨版本:建議性路由提示成為正式的唯讀指令,友善的 CLI 輸出擴展到 `run` 之外,v1.2.0 的功能獲得完整文件化,並附上可錄製的示範情境。硬性限制不變:本地優先、確定性、僅 subprocess、confirmation-first、無常駐程式。

## 新增

- **`relay-baton route "<task>" [--json]`** — 建議性路由提示的唯讀預覽。與 `run` 完全一致地解析鏈路(旗標 > work-item 指派 > 專案 > config),然後展示註冊表 `strengths` 標籤會如何為該任務重新排序,並列出各 agent 匹配的關鍵字。不啟動 agent,也不寫入工作階段狀態。
- **示範情境** — `scripts/demo/demo.sh` + `scripts/demo/fake-agent.mjs`:用 fake agent 確定性地重現 fallback → compact handoff → 續跑流程(不執行真實 codex/claude,不消耗配額)。用 `asciinema rec -c "bash scripts/demo/demo.sh" demo.cast` 錄製。

## 改進

- **友善輸出全面鋪開** — v1.2.0 的 `ui` 風格(✓ / ✗ / ▲ 及「接下來做什麼」提示)現在也涵蓋 `doctor`、`init`、`status`、`login`、`handoff`。`doctor`/`login` 先前硬編碼 ANSI 並忽略 `NO_COLOR`/非 TTY,現在能正確降級為純文字。
- **`doctor` 顯示觸發器狀態** — 一行 Core info 回報可選的 `handoffTriggers` 區塊是否已設定,讓 v1.2.0 功能可被發現。
- **文件完備** — `--handoff-now`、`handoffTriggers` 設定區塊(含範例 JSON)、路由提示與 `route` 已寫入 `docs/COMMANDS.md`(EN+KO)、指南(EN+KO)及 README 設定一節。

## 相容性

- 無破壞性變更;無 config/工件 schema 變更。`route` 為純新增。
