# v1.7.0 — 選擇模型，在模型之間回退

現在可以為每個 agent CLI 選擇**使用哪個模型**，並且不只在 agent 之間、也能在同一 agent 的不同模型之間接力。

## 變更

- `run` / `plan` / `execute` / `handoff` 新增 **`--model <id>`**，傳給 agent CLI 本身的模型參數（`codex exec -m`、`claude --model`、`gemini -m` …）。任意 id 皆可，新模型無需更新。
- config 支援每個 agent 的預設模型 `agents.<id>.model`；未設定時沿用 CLI 預設。
- **同一 agent 內的模型回退**：`--chain claude:claude-opus-5-5,claude:claude-sonnet-5,codex`。
- **桌面版模型選擇框**（Codex/Claude 切換旁）：提供最新模型建議，也可手動輸入；留空 = CLI 預設。
- 擴大回退偵測：`overloaded_error`、`resource_exhausted`、`credit balance is too low`、`context window exceeded`。
- `session.json` 記錄 `activeModel` / `reportedModel`。

## 相容性

- 純新增。不使用 `--model` 時指令與 v1.6.x 完全相同。
