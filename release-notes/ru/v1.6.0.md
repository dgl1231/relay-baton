# v1.6.0 — Современный установщик Windows

Десктоп-приложение для Windows теперь поставляется как **фирменный
установщик NSIS** вместо классического мастера MSI.

## Что изменилось

- **`…-setup.exe` (NSIS), а не `…_en-US.msi`.** Современный установщик с
  тёпло-тёмной панелью приветствия в стиле приложения — повёрнутый оранжевый
  ромб, логотип `relay-baton` и слоган `codex → claude handoff`.
- **Установка для пользователя, без запроса UAC.** Ставится в ваш профиль
  пользователя, как VS Code или Discord — без диалога «разрешить этому
  приложению вносить изменения» и без прав администратора.

## Обновление с установки MSI

Сборка NSIS — это другой тип установщика. Если вы ставили предыдущую версию
из MSI, удалите её один раз через **Параметры → Приложения** (или старый
ярлык «Uninstall relay-baton»), затем запустите новый `…-setup.exe`.
Дальнейшие обновления останутся на установщике NSIS.

## Не затронуто

- **Пользователи CLI** (npm / Homebrew / Scoop / Winget) — без изменений. Эти
  каналы ставят автономный бинарник `relay-baton`, не зависящий от
  десктопного установщика.
- macOS `.dmg` и Linux `.AppImage` — без изменений.
- Поведение CLI и приложения не изменилось; версии повышены синхронно.
