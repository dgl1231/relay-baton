# v1.7.0 — Выбор модели и fallback между моделями

relay-baton теперь умеет выбирать, **какую модель** использует каждый CLI агента, и передавать эстафету между моделями одного агента, а не только между агентами.

## Что изменилось

- **`--model <id>`** для `run`, `plan`, `execute` и `handoff` — передаётся во флаг модели CLI (`codex exec -m`, `claude --model`, `gemini -m`, …). Подходит любой id, новые модели работают без обновления.
- Модель по умолчанию для агента в конфиге: `agents.<id>.model`. Если не задана — как раньше, значение CLI.
- **Fallback между моделями одного агента**: `--chain claude:claude-opus-5-5,claude:claude-sonnet-5,codex`.
- **Выбор модели в десктоп-приложении** рядом с переключателем Codex/Claude: подсказки актуальных моделей или любой id. Пусто = значение CLI.
- Расширено обнаружение fallback: `overloaded_error`, `resource_exhausted`, `credit balance is too low`, `context window exceeded`.
- `session.json` записывает `activeModel` / `reportedModel`.

## Совместимость

- Только добавления. Без `--model` команды идентичны v1.6.x.
