# v1.5.0 — Запуск агентов из десктоп-приложения

Agent Room перестаёт быть просмотрщиком: теперь он может по-настоящему
запускать агентов — **confirmation-first**, ровно так, как всегда
предписывал проектный документ AGENT_ROOM (preview → confirm → run). Без
вашего клика ничего не запускается.

## `/run <task>` и «Запустить здесь»

- Новая команда композера **`/run <task>`**: собирает
  `relay-baton run "<task>" --primary <выбранный агент> --pretty` —
  переключатель Codex/Claude в шапке теперь действительно решает, кто
  пойдёт первым.
- **`/plan`, `/execute`, `/handoff`** тоже собирают настоящие команды
  запуска (у handoff убран `--no-run`).
- Каждая открывает существующее окно подтверждения с **точной командой**;
  новая кнопка **«Run here»** выполняет её через встроенный sidecar CLI
  (ваши локальные логины и квоты — relay-baton по-прежнему не вызывает
  API провайдеров напрямую). Копирование в терминал осталось.

## Живая карточка выполнения

Вывод агента стримится в живую карточку таймлинии (формат `--pretty`):
вызовы инструментов, текст ассистента и итоговый чек токенов/стоимости
появляются в реальном времени. Кнопка **Cancel** убивает процесс; по
завершении карточка получает зелёный чип `done` или красный `exit N`, а
панели обновляются. Одно выполнение за раз; вывод ограничен последними 400
строками; карточка переживает перезагрузки таймлинии, как любая карточка
v1.4.1.

## Внутреннее / совместимость

- Новые capabilities Tauri: `shell:allow-spawn` (ограничен sidecar) и
  `shell:allow-kill` для отмены (с одним только execute стриминговые
  запуски были бы запрещены).
- GUI по-прежнему без бизнес-логики: он запускает CLI и показывает строки.
  Все гейты (качество handoff, token diet, redaction, guardrails) работают
  в CLI так же, как из терминала.
- Тексты гида/подсказок обновлены на всех 4 языках GUI — теперь это
  «confirmation-first dashboard», а не read-only.
- Поведение CLI не изменилось; версии повышаются синхронно.
