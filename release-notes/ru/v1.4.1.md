# v1.4.1 — Полировка десктопной таймлинии

Два исправления удобства для таймлинии Agent Room, оба найдены при реальном
использовании десктоп-приложения v1.4.0. Только десктоп — поведение CLI не
меняется; версии повышаются синхронно.

## Карточки результатов переживают перезагрузку таймлинии

В v1.4.0 карточка результата slash-команды исчезала, как только следующая
команда перезагружала таймлинию — видна была только самая свежая карточка
(существовавшее ранее поведение, ставшее куда заметнее с появлением
карточек). Локальные карточки теперь хранятся в памяти и при каждой
перезагрузке заново сливаются с таймлинией по временной метке — серия команд
оставляет читаемую историю. При переключении проекта они очищаются (они
описывают предыдущий проект), лимит — 50 последних.

## Строки таймлинии с цветовой кодировкой ролей

События user и relay-baton отрисовывались одинаково — тот же фон, та же
рамка — и разговор сливался. Теперь строки кодируются цветом по говорящему:

- **user** — синяя левая граница и более светлый фон; команды моноширинным
  шрифтом
- **relay-baton** — янтарная левая граница
- **claude** / **codex** — их агентские цвета (как в переключателе шапки)

Работает в тёмной и светлой темах.
