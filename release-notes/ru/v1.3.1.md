# v1.3.1 — Хотфикс десктопа

**Исправлено: десктоп-приложение вообще не запускалось** в неподписанных сборках
(все MSI/DMG/AppImage с момента появления апдейтера). Rust-оболочка безусловно
регистрировала плагин Tauri updater, но пайплайн релиза внедряет конфигурацию
`plugins.updater` только при наличии секретов подписи — поэтому неподписанные
сборки падали с паникой при старте (exit 101), не показав ни одного окна.

Теперь плагин updater регистрируется только при наличии его блока конфигурации.
Изменений CLI нет — пользователей npm/Homebrew/Scoop/Winget это не затрагивает.
