# v1.2.0 — Умнее эстафета & дружелюбный UI

> Примечание: имена тегов v1.1.x были заняты до-GA линией «Distributable», поэтому первый функциональный релиз после GA выходит как v1.2.0.

Первый функциональный релиз после GA: v2.8 «Smarter relay» и улучшения UX в CLI/десктопе. Жёсткие ограничения без изменений: local-first, детерминизм, только subprocess, confirmation-first, без демона.

## Добавлено

- **Расширенные триггеры хэндоффа (opt-in).** Новый необязательный блок `handoffTriggers` (`budgetRatio` / `changedFiles` / `usageTokensProxy`): позволяет *предложить* передачу эстафеты, даже если не сработал шаблон ошибки fallback. При достижении порога — запрос y/N (или `--yes`); без настройки обнаружение остаётся только по шаблонам ошибок. Core: `HandoffTriggerPolicy`.
- **Ручной триггер хэндоффа.** `relay-baton run --handoff-now` передаёт эстафету следующему агенту после каждого хопа, не дожидаясь сигнала fallback (сам флаг — это явное согласие).
- **Рекомендательные подсказки маршрутизации.** Агенты в реестре получают ключевые теги `strengths`; `suggestChain` предлагает порядок цепочки, и `run` выводит однострочную подсказку только при отличии. Только отображение — явные `--chain`/`--primary` всегда важнее.

## Улучшено

- **Дружелюбный вывод CLI.** Новые помощники `ui` без зависимостей (✓ / ✗ / ▲ / → с приглушёнными подсказками «что попробовать дальше»); вывод `run` с заголовками хопов и более понятными отказами gate. Цвет автоматически отключается при пайпе или `NO_COLOR`.
- **Тёплый рестайл десктопа.** Webview Tauri получает тёплую палитру (кремовая светлая тема, тёплая тёмная тема, терракотовый акцент), sans-шрифт для интерфейса, более мягкие скругления/тени и события беседы в виде карточек. Только отображение — webview по-прежнему обращается только к CLI sidecar.

## Исправлено

- Запросы подтверждения `run` больше не зависают навсегда, когда stdin не TTY (CI/пайп) — они автоматически отклоняются с подсказкой передать `--yes`.
- Windows CI: сравнение путей в тесте worktree теперь разворачивает короткие пути 8.3.

## Совместимость

- Без ломающих изменений. Новый ключ `handoffTriggers` необязателен и валидируется; схемы артефактов не изменены.
