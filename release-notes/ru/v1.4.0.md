# v1.4.0 — Дружелюбный поток агента и карточки результатов на десктопе

Вывод агента наконец читается как разговор, а не как дамп логов — и в CLI, и
в десктоп-приложении.

## `--pretty`: дружелюбный поток агента (CLI)

`run`, `plan`, `execute` и `handoff` принимают новый опциональный флаг
`--pretty`. Он запрашивает у CLI агента машиночитаемый поток событий
(`claude -p --output-format stream-json --verbose`, `codex exec --json`) и
рендерит его в удобочитаемые строки:

```
● model claude-sonnet-5 · session abc123
  · thinking: need to look at the failing test first
→ Bash: pnpm test --filter core
Fixed the flaky test — two files changed.
✓ agent turn done — in 10,231 tok · out 1,892 tok · $0.0231 · 48.2s
```

- Только детерминированный построчный разбор JSONL — без вызовов модели и
  без суммаризации (`parseEvent` адаптеров Codex/Claude).
- Строки, которые не парсятся, — и агенты без структурированного режима —
  проходят как есть; полный сырой поток по-прежнему пишется в
  `.ai-session/commands.log`.
- Обнаружение fallback не меняется: паттерны продолжают матчиться по сырым
  строкам, включая текст ошибок внутри JSON-событий.
- Флаг опциональный, потому что старые версии CLI агента могут его не
  поддерживать.

## Десктоп: структурированные карточки результатов в Agent Room

Результаты slash-команд (`/status`, `/budget`, `/git`, `/review`, `/guard`,
`/risk`, `/checkpoints`, `/sessions`, `/resume`, `/workspace`, `/profile`,
`/inventory`, `/inspect`, `/bundle`) теперь рендерятся как структурированные
карточки — чипы статуса, индикатор budget, git-строки по файлам, чек-лист
шагов плана — вместо сырых дампов `JSON.stringify`. Каждая карточка хранит
полный payload за свёрнутой секцией **raw json**. Всё это display-only
DOM-билдеры; в webview по-прежнему нет бизнес-логики.

Исправлено: результаты `/review` исчезали из таймлайна сразу после рендера
(перезагрузка таймлайна затирала карточку).

## Совместимость

- `--pretty` опционален; вывод по умолчанию не меняется.
- `AgentEvent` получает новые типы событий (`system`, `assistant_text`,
  `reasoning`, `tool_use`, `usage`) — аддитивно, существующие потребители не
  затронуты.
- Изменений config и схемы сессии нет.
