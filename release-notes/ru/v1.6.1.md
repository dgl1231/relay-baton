# v1.6.1 — Установка Windows в один клик

Продолжение установщика NSIS из v1.6.0: установка в Windows теперь
завершается в **один клик** вместо прохождения мастера.

## Что изменилось

- **Больше нет страниц мастера.** Шаги приветствия и «Выбор папки установки»
  убраны. Двойной клик по `…-setup.exe` устанавливает сразу в стандартную
  папку пользователя и показывает фирменный финальный экран — ближе к тому,
  как ставятся современные приложения (Discord, VS Code), когда рамка уходит с
  дороги.
- Тёпло-тёмная фирменная графика (оранжевый ромб + логотип `relay-baton`)
  по-прежнему появляется на финальном экране и в шапке хода установки.
- По-прежнему **для пользователя, без запроса UAC** (с v1.6.0).

## Под капотом

- Кастомный шаблон NSIS
  (`desktop/src-tauri/installer/installer.nsi`, на основе официального шаблона
  Tauri и с совпадающей версией) пропускает страницы приветствия и каталога
  через уже имеющийся в шаблоне хук `Skip`. При обновлении по-прежнему
  показывается запрос на переустановку.

## Не затронуто

- Каналы CLI (npm / Homebrew / Scoop / Winget), macOS `.dmg` и Linux
  `.AppImage` — без изменений. Поведение CLI и приложения не изменилось;
  версии повышены синхронно.
