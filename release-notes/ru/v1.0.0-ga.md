# v1.0.0 — Общая доступность (GA)

Первый публичный релиз общей доступности (GA). relay-baton уходит с бесконечной
линии `-alpha.N`. Изменений функциональности относительно последней alpha нет;
этот релиз делает проект **юридически пригодным к использованию и устанавливаемым**.

> Это заметка **GA** для тега `v1.0.0`. Более ранний
> [`v1.0.0.md`](../v1.0.0.md) описывает до-GA веху «Stable Local Release» и
> сохранён для истории.

## Добавлено

- **MIT `LICENSE`** в корне репозитория (ранее без лицензии = «all rights
  reserved»). `license: "MIT"` в каждом манифесте пакета.
- **Публикация в npm** — CLI выходит как **`@relay-baton/cli`** (ставит привычную
  команду `relay-baton`), плюс публичные библиотеки
  `@relay-baton/core`·`shared`·`tui`. `npm i -g @relay-baton/cli` /
  `npx @relay-baton/cli` работают без клонирования.
- **Пакетные менеджеры** — Homebrew tap (`dgl1231/homebrew-relay-baton`), Scoop
  bucket (`dgl1231/scoop-relay-baton`) и Winget (`dgl1231.relay-baton`).
- **`CHANGELOG.md`** + конвейер релиза, который по одному тегу раскладывает по
  всем каналам (npm/Homebrew/Scoop/Winget).

## Изменено

- Все пакеты в версии **1.0.0**; GA-версионирование заменяет `-alpha.N`.

## Жёсткие ограничения (без изменений, зафиксированы тестами)

- Никаких прямых вызовов API OpenAI/Anthropic; только subprocess через локальные
  CLI `codex`/`claude`. Без хранения/вывода API-ключей. Без авто commit/push/PR;
  без демона; только детерминированная компактизация.
