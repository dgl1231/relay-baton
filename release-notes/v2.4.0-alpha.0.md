# v2.4.0-alpha.0 — Smarter handoff

v2.4 "Smarter handoff" — spend fewer tokens per handoff and surface local usage,
all still deterministic with no embeddings. Both roadmap items ship in this alpha.

## Added

- **Deterministic compaction v2.**
  - `SymbolOutline` extracts a compact symbol/heading outline via language-aware
    regexes (TS/JS, Python, C#, Go, Rust, Java, plus Markdown headings). The repo
    map now carries a **"## Symbols (changed + key files)"** section so the next
    agent sees structure, not just a directory tree.
  - `DiffCompactor.compactRanked` ranks diff chunks by relevance to the task
    (path mention, directory proximity, source>test>doc weight, shallow-path
    bias) so the most relevant file diffs survive the budget first; `buildHandoff`
    uses it. Skipped lock/build/binary chunks sink to the bottom. No embeddings.
- **Local usage insight.** `UsageLedger` keeps an append-only per-session ledger
  (`.ai-session/usage.jsonl`) of a token/quota **proxy** (`ceil(chars/4)`, not a
  real tokenizer); `run`/`handoff` record a handoff event each time. New
  `relay-baton usage [--json]` aggregates totals, per-type/per-agent breakdown,
  handoff count, and a budget ratio vs the active profile. **Local only — never
  transmitted.**

## Hard constraints

Unchanged: local subprocess only, deterministic, no direct LLM API client, no
exact tokenizer, no semantic/vector indexing, no network, no auto
commit/push/PR.
