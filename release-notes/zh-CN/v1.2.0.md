# v1.2.0 — 更智能的接力 & 友好的 UI

> 注:v1.1.x 的标签名已被 GA 前的「Distributable」线使用,因此 GA 后的第一个功能版本以 v1.2.0 发布。

作为 GA 后的第一个功能版本,收录了 v2.8「Smarter relay」以及 CLI/桌面的体验改进。硬约束不变:本地优先、确定性、仅 subprocess、confirmation-first、无守护进程。

## 新增

- **扩展的接力触发(opt-in)。** 新增可选配置 `handoffTriggers`(`budgetRatio` / `changedFiles` / `usageTokensProxy`):即使没有出现 fallback 错误模式,也会 *建议* 交棒。达到阈值时 y/N 确认(或 `--yes`);未配置则保持仅按错误模式检测。核心:`HandoffTriggerPolicy`。
- **手动接力触发。** `relay-baton run --handoff-now` 不等待 fallback 信号,在每个 hop 之后交给下一个 agent(该标志本身即为明确同意)。
- **建议性路由提示。** 注册表中的 agent 增加 `strengths` 关键词标签;`suggestChain` 为任务提出链路顺序建议,仅当顺序不同时 `run` 才输出一行提示。仅显示 — 显式的 `--chain`/`--primary` 始终优先。

## 改进

- **友好的 CLI 输出。** 零依赖的 `ui` 助手(✓ / ✗ / ▲ / → 以及「接下来该做什么」的提示);`run` 输出改用 hop 标题与更清晰的 gate 失败展示。管道输出或设置 `NO_COLOR` 时自动关闭颜色。
- **桌面暖色重塑。** Tauri webview 采用暖色调色板(奶油色浅色、暖色深色、赤陶强调色)、界面使用无衬线字体、更柔和的圆角/阴影,以及消息卡片式的会话事件。仅显示 — webview 仍然只调用 CLI sidecar。

## 修复

- 当 stdin 不是 TTY(CI/管道)时,`run` 的确认提示不再永久挂起 —— 会自动拒绝并提示传入 `--yes`。
- Windows CI:worktree 测试的路径比较现在会展开 8.3 短路径。

## 兼容性

- 无破坏性变更。新配置键 `handoffTriggers` 为可选并会被校验;工件 schema 未变。
