# v1.7.0 — 选择模型，在模型之间回退

现在可以为每个 agent CLI 选择**使用哪个模型**，并且不仅能在 agent 之间、也能在同一 agent 的不同模型之间接力。

## 变更

- `run` / `plan` / `execute` / `handoff` 新增 **`--model <id>`**，传给 agent CLI 自身的模型参数（`codex exec -m`、`claude --model`、`gemini -m` …）。任意 id 均可，新模型无需更新。
- config 支持每个 agent 的默认模型 `agents.<id>.model`；未设置时沿用 CLI 默认。
- **同一 agent 内的模型回退**：`--chain claude:claude-opus-5-5,claude:claude-sonnet-5,codex`。
- **桌面端模型选择框**（Codex/Claude 切换旁）：提供最新模型建议，也可手动输入；留空 = CLI 默认。
- 扩展回退检测：`overloaded_error`、`resource_exhausted`、`credit balance is too low`、`context window exceeded`。
- `session.json` 记录 `activeModel` / `reportedModel`。

## 兼容性

- 纯新增。不使用 `--model` 时命令与 v1.6.x 完全一致。
