# v1.3.0 — 路由预览 & 打磨

GA 后的打磨版本:建议性路由提示成为正式的只读命令,友好的 CLI 输出扩展到 `run` 之外,v1.2.0 的功能得到完整文档化,并附带可录制的演示场景。硬约束不变:本地优先、确定性、仅 subprocess、confirmation-first、无守护进程。

## 新增

- **`relay-baton route "<task>" [--json]`** — 建议性路由提示的只读预览。与 `run` 完全一致地解析链路(标志 > work-item 分配 > 项目 > config),然后展示注册表 `strengths` 标签会如何为该任务重新排序,并给出各 agent 匹配的关键词。不启动 agent,也不写会话状态。
- **演示场景** — `scripts/demo/demo.sh` + `scripts/demo/fake-agent.mjs`:用 fake agent 确定性地重现 fallback → compact handoff → 续跑流程(不运行真实 codex/claude,不消耗配额)。用 `asciinema rec -c "bash scripts/demo/demo.sh" demo.cast` 录制。

## 改进

- **友好输出全面铺开** — v1.2.0 的 `ui` 风格(✓ / ✗ / ▲ 及「接下来做什么」提示)现在也覆盖 `doctor`、`init`、`status`、`login`、`handoff`。`doctor`/`login` 此前硬编码 ANSI 并忽略 `NO_COLOR`/非 TTY,现在能正确降级为纯文本。
- **`doctor` 显示触发器状态** — 一行 Core info 报告可选的 `handoffTriggers` 块是否已配置,让 v1.2.0 功能可被发现。
- **文档完备** — `--handoff-now`、`handoffTriggers` 配置块(含示例 JSON)、路由提示与 `route` 已写入 `docs/COMMANDS.md`(EN+KO)、指南(EN+KO)及 README 配置一节。

## 兼容性

- 无破坏性变更;无 config/工件 schema 变更。`route` 为纯新增。
