# v1.6.1 — 一键 Windows 安装

v1.6.0 NSIS 安装程序的跟进：Windows 安装现在无需向导，**一键**完成。

## 变更内容

- **移除向导页面。** 欢迎界面和"选择安装位置"步骤都没了。双击
  `…-setup.exe` 会直接安装到默认的按用户位置，并显示品牌完成界面 —— 更接近
  Discord、VS Code 等现代应用的安装方式，让框架不再挡路。
- 暖色深色品牌图案（橙色菱形 + `relay-baton` 字标）仍出现在完成界面和安装
  进度头部。
- 仍为 **按用户安装，无 UAC 提示**（自 v1.6.0 起）。

## 底层

- 自定义 NSIS 模板（`desktop/src-tauri/installer/installer.nsi`，基于 Tauri
  官方模板并版本匹配）通过模板中已有的 `Skip` 钩子跳过欢迎/目录页面。升级时
  仍会显示重新安装确认界面。

## 不受影响

- CLI 渠道（npm / Homebrew / Scoop / Winget）、macOS `.dmg` 与 Linux
  `.AppImage` —— 不变。无 CLI 或应用行为变更；版本同步递增。
