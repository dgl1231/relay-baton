# v1.6.0 — 现代化的 Windows 安装程序

Windows 桌面应用现在以**品牌化的 NSIS 安装程序**发布，取代了经典的 MSI
向导。

## 变更内容

- **`…_en-US.msi` → `…-setup.exe`（NSIS）。** 与应用统一的暖色深色欢迎面板
  的现代安装界面 —— 旋转的橙色菱形标记、`relay-baton` 字标，以及
  `codex → claude handoff` 标语。
- **按用户安装，无 UAC 提示。** 像 VS Code 或 Discord 一样安装到你的用户
  配置文件 —— 没有"允许此应用进行更改"对话框，也不需要管理员权限。

## 从 MSI 安装升级

NSIS 版本是不同的安装类型。如果你之前用 MSI 安装了旧版本，请先从**设置 →
应用**（或旧的"Uninstall relay-baton"快捷方式）卸载一次，然后运行新的
`…-setup.exe`。之后的更新将继续使用 NSIS 安装程序。

## 不受影响

- **CLI 用户**（npm / Homebrew / Scoop / Winget）—— 不变。这些渠道安装的是
  独立于桌面安装程序的 `relay-baton` 单文件二进制。
- macOS `.dmg` 与 Linux `.AppImage` —— 不变。
- 无 CLI 或应用行为变更；版本同步递增。
