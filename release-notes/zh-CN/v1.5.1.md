# v1.5.1 — 诚实的运行结束 & 更安静的实时输出

对 v1.5.0"在桌面应用中运行 agent"的两个小跟进，都是在实机验证真实
`/run` 时发现的。

## 失败结束现在可区分

当 relay chain 结束于一个**运行了但以非零退出**的 agent 时，`run`（和
`execute`）仍然以 `0` 退出。在桌面应用上，即便流式输出以
`✗ <agent> exited with code N` 结尾，运行卡片也显示绿色 `完成` 徽章。
现在这些结束会以 **`4`** 退出，因此运行卡片会把徽章标红，脚本也能区分
失败结束与正常结束。

`run`/`execute` 完整退出码：`0` 成功 · `1` 无法 spawn agent · `2` 用法错误
· `3` quality gate 阻止了 handoff · `4` 链结束于失败的 agent。

## 更安静的实时运行卡片

Claude 会在回合中途输出常规的 `rate_limit_event` 遥测行。它们不是已识别
的事件，此前会以 raw 形式透传到实时卡片。现在从显示中抑制它们（raw 行仍
到达 fallback 检测和磁盘日志 —— 无信息丢失）。

## 兼容性

- 无新命令或标志；唯一新增的外部行为是退出码 `4`。
- 桌面与 CLI 版本同步递增。
