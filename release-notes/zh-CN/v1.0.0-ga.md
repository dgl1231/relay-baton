# v1.0.0 — 正式发布 (GA)

首个公开的正式发布(GA)。relay-baton 结束了长期的 `-alpha.N` 线。相较上一个 alpha
无功能变更;本次发布让项目 **在法律上可用且可安装**。

> 这是 `v1.0.0` 标签的 **GA** 说明。此前的
> [`v1.0.0.md`](../v1.0.0.md) 记录的是 GA 之前的「Stable Local Release」里程碑,
> 保留作为历史。

## 新增

- 仓库根目录的 **MIT `LICENSE`**(此前无许可证 = "all rights reserved")。
  每个包 manifest 均含 `license: "MIT"`。
- **npm 发布** — CLI 以 **`@relay-baton/cli`** 发布(安装熟悉的 `relay-baton`
  命令),另有公开库 `@relay-baton/core`·`shared`·`tui`。
  无需 clone 即可 `npm i -g @relay-baton/cli` / `npx @relay-baton/cli`。
- **包管理器** — Homebrew tap(`dgl1231/homebrew-relay-baton`)、Scoop
  bucket(`dgl1231/scoop-relay-baton`)、Winget(`dgl1231.relay-baton`)。
- **`CHANGELOG.md`** + 一个标签即可向全渠道(npm/Homebrew/Scoop/Winget)自动分发的
  发布流水线。

## 变更

- 所有包版本升至 **1.0.0**;GA 版本方案取代 `-alpha.N`。

## 硬约束(不变,由测试锁定)

- 不直接调用 OpenAI/Anthropic API;仅通过本地 `codex`/`claude` CLI subprocess。
  不存储/打印 API key。无自动 commit/push/PR;无守护进程;仅确定性压缩。
