# v1.4.1 — 桌面端时间线打磨

在实际使用 v1.4.0 桌面应用时发现的 Agent Room 时间线体验修复 2 项。仅桌面端
— CLI 行为无变化；版本号同步递增。

## 结果卡片在时间线重载后保留

在 v1.4.0 中，斜杠命令的结果卡片会在下一条命令重载时间线时立即消失——任何
时刻都只能看到最新一张卡片（这是历史行为，只是结果变成卡片后明显得多）。
现在本地结果卡片保存在内存中，每次重载时按时间戳重新合并回时间线——连续
执行命令也能留下可读的历史。切换项目时清空（卡片描述的是上一个项目），
最多保留最近 50 张。

## 按角色着色的时间线行

user 与 relay-baton 的事件此前以相同背景、相同边框渲染，对话混在一起难以
区分。现在行按发言者着色：

- **user** — 蓝色左边框 + 更亮的背景，命令以 monospace 显示
- **relay-baton** — 琥珀色左边框
- **claude** / **codex** — 各自的 agent 颜色（与顶部切换按钮一致）

深色/浅色主题均支持。
