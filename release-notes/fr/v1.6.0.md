# v1.6.0 — Installateur Windows moderne

L'app de bureau Windows est désormais distribuée comme un **installateur NSIS
aux couleurs de la marque** au lieu du classique assistant MSI.

## Ce qui change

- **`…-setup.exe` (NSIS), plus `…_en-US.msi`.** Un installateur moderne avec un
  panneau d'accueil sombre et chaleureux assorti à l'app — le losange orange
  pivoté, le logotype `relay-baton` et le slogan `codex → claude handoff`.
- **Installation par utilisateur, sans invite UAC.** S'installe dans votre
  profil utilisateur comme VS Code ou Discord — pas de boîte de dialogue
  « autoriser cette app à apporter des modifications », pas de droits admin.

## Mise à niveau depuis une installation MSI

La build NSIS est un type d'installateur distinct. Si vous aviez installé une
version précédente via le MSI, désinstallez-la une fois depuis **Paramètres →
Applications** (ou l'ancien raccourci « Uninstall relay-baton »), puis lancez
le nouveau `…-setup.exe`. Les futures mises à jour restent sur l'installateur
NSIS.

## Non affecté

- **Utilisateurs CLI** (npm / Homebrew / Scoop / Winget) — inchangé. Ces
  canaux installent le binaire `relay-baton` autonome, indépendant de
  l'installateur de bureau.
- `.dmg` macOS et `.AppImage` Linux — inchangés.
- Aucun changement CLI ni de comportement de l'app ; versions en lockstep.
