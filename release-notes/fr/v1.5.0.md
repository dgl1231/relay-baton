# v1.5.0 — Lancer des agents depuis l'app de bureau

L'Agent Room n'est plus un simple visualiseur : il peut désormais lancer de
vrais agents — **confirmation-first**, exactement comme le document de
conception AGENT_ROOM l'a toujours spécifié (preview → confirm → run). Rien
ne s'exécute sans votre clic.

## `/run <task>` et « Exécuter ici »

- Nouvelle commande composer **`/run <task>`** : construit
  `relay-baton run "<task>" --primary <agent sélectionné> --pretty` — le
  toggle Codex/Claude de l'en-tête décide désormais vraiment qui part en
  premier.
- **`/plan`, `/execute`, `/handoff`** construisent aussi de vraies commandes
  de lancement (handoff a perdu `--no-run`).
- Chacune ouvre le modal de confirmation existant avec la **commande
  exacte** ; le nouveau bouton **« Run here »** l'exécute via le sidecar CLI
  embarqué (vos logins et quotas locaux — relay-baton n'appelle toujours
  aucune API fournisseur). La copie vers le terminal reste disponible.

## Carte d'exécution en direct

La sortie de l'agent est diffusée dans une carte en direct de la timeline
(format `--pretty`) : appels d'outils, texte de l'assistant et reçu final
tokens/coût apparaissent en temps réel. Un bouton **Cancel** tue le
processus ; à la fin, la carte reçoit un chip vert `done` ou rouge `exit N`
et les panneaux se rafraîchissent. Une exécution à la fois ; sortie limitée
aux 400 dernières lignes ; la carte survit aux rechargements comme toute
carte v1.4.1.

## Interne / compatibilité

- Nouvelles capabilities Tauri : `shell:allow-spawn` limité au sidecar et
  `shell:allow-kill` pour l'annulation (execute seul aurait refusé les
  exécutions en streaming).
- La GUI reste sans logique métier : elle lance la CLI et affiche des
  lignes. Toutes les barrières (qualité de handoff, token diet, redaction,
  guardrails) tournent dans la CLI comme depuis un terminal.
- Textes de guide/infobulles mis à jour dans les 4 langues de la GUI —
  c'est désormais un « confirmation-first dashboard », plus un tableau en
  lecture seule.
- Comportement CLI inchangé ; versions en lockstep.
