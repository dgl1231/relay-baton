# v1.7.0 — Choisir le modèle, basculer entre modèles

relay-baton peut désormais choisir **quel modèle** chaque CLI d'agent utilise, et passer le relais entre modèles d'un même agent, pas seulement entre agents.

## Changements

- **`--model <id>`** sur `run`, `plan`, `execute` et `handoff`, transmis à l'option de modèle de la CLI (`codex exec -m`, `claude --model`, `gemini -m`, …). N'importe quel id : les nouveaux modèles fonctionnent sans mise à jour.
- Modèle par défaut par agent dans la config : `agents.<id>.model`. Absent = défaut de la CLI, comme avant.
- **Bascule entre modèles du même agent** : `--chain claude:claude-opus-5-5,claude:claude-sonnet-5,codex`.
- **Sélecteur de modèle dans l'app de bureau**, à côté du choix Codex/Claude : suggestions des modèles actuels ou saisie libre. Vide = défaut de la CLI.
- Détection de bascule élargie : `overloaded_error`, `resource_exhausted`, `credit balance is too low`, `context window exceeded`.
- `session.json` enregistre `activeModel` / `reportedModel`.

## Compatibilité

- Purement additif. Sans `--model`, les commandes sont identiques à v1.6.x.
