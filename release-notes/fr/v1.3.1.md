# v1.3.1 — Correctif bureau

**Corrige l'application de bureau qui ne s'ouvrait pas du tout** sur les builds
non signés (tous les MSI/DMG/AppImage depuis l'introduction de l'updater). Le
shell Rust enregistrait le plugin updater de Tauri sans condition, mais le
pipeline n'injecte la config `plugins.updater` que lorsque les secrets de
signature existent — les builds non signés paniquaient donc au démarrage
(exit 101) avant d'afficher la moindre fenêtre.

Le plugin updater n'est désormais enregistré que si son bloc de configuration
est présent. Aucun changement CLI — les utilisateurs npm/Homebrew/Scoop/Winget
ne sont pas concernés.
