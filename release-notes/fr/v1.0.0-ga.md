# v1.0.0 — Disponibilité générale (GA)

Première version publique en disponibilité générale (GA). relay-baton quitte la
ligne perpétuelle `-alpha.N`. Aucun changement de fonctionnalités par rapport à
la dernière alpha ; cette version rend le projet **légalement utilisable et
installable**.

> Ceci est la note **GA** du tag `v1.0.0`. L'ancien
> [`v1.0.0.md`](../v1.0.0.md) documente le jalon « Stable Local Release » d'avant
> GA et est conservé pour l'historique.

## Ajouté

- **`LICENSE` MIT** à la racine du dépôt (auparavant sans licence = "all rights
  reserved"). `license: "MIT"` dans chaque manifeste de paquet.
- **Distribution npm** — le CLI est publié en **`@relay-baton/cli`** (installe la
  commande familière `relay-baton`), plus les bibliothèques publiques
  `@relay-baton/core`·`shared`·`tui`. `npm i -g @relay-baton/cli` /
  `npx @relay-baton/cli` fonctionnent sans cloner.
- **Gestionnaires de paquets** — tap Homebrew (`dgl1231/homebrew-relay-baton`),
  bucket Scoop (`dgl1231/scoop-relay-baton`) et Winget (`dgl1231.relay-baton`).
- **`CHANGELOG.md`** + un pipeline de release qui diffuse vers tous les canaux
  (npm/Homebrew/Scoop/Winget) avec un seul tag.

## Modifié

- Tous les paquets en version **1.0.0** ; le versionnage GA remplace `-alpha.N`.

## Contraintes fortes (inchangées, verrouillées par les tests)

- Aucun appel direct à l'API OpenAI/Anthropic ; subprocess uniquement via les CLI
  locaux `codex`/`claude`. Pas de stockage/impression de clés API. Pas de
  commit/push/PR automatique ; pas de démon ; compaction déterministe uniquement.
