# v1.4.0 — Flux d'agent convivial et cartes de résultats sur le bureau

La sortie de l'agent se lit enfin comme une conversation, pas comme un dump de
logs — dans la CLI comme dans l'application de bureau.

## `--pretty` : flux d'agent convivial (CLI)

`run`, `plan`, `execute` et `handoff` acceptent le nouveau flag opt-in
`--pretty`. Il demande au CLI de l'agent son flux d'événements lisible par
machine (`claude -p --output-format stream-json --verbose`, `codex exec
--json`) et le rend sous forme de lignes lisibles :

```
● model claude-sonnet-5 · session abc123
  · thinking: need to look at the failing test first
→ Bash: pnpm test --filter core
Fixed the flaky test — two files changed.
✓ agent turn done — in 10,231 tok · out 1,892 tok · $0.0231 · 48.2s
```

- Parsing JSONL déterministe ligne par ligne uniquement — aucun appel de
  modèle, aucun résumé (`parseEvent` de l'adapter Codex/Claude).
- Les lignes non parsées — et les agents sans mode structuré — repassent en
  passthrough brut ; le flux brut complet est toujours écrit dans
  `.ai-session/commands.log`.
- La détection de fallback est inchangée : les motifs continuent de matcher
  sur les lignes brutes, y compris le texte d'erreur dans les événements JSON.
- Opt-in car d'anciennes versions du CLI de l'agent peuvent ne pas supporter
  ces flags.

## Bureau : cartes de résultats structurées dans l'Agent Room

Les résultats des commandes slash (`/status`, `/budget`, `/git`, `/review`,
`/guard`, `/risk`, `/checkpoints`, `/sessions`, `/resume`, `/workspace`,
`/profile`, `/inventory`, `/inspect`, `/bundle`) sont désormais rendus en
cartes structurées — chips de statut, jauge de budget, lignes git par
fichier, checklist des étapes du plan — au lieu de dumps `JSON.stringify`.
Chaque carte conserve le payload complet derrière une section **raw json**
repliée. Uniquement des builders DOM d'affichage ; la webview ne contient
toujours aucune logique métier.

Corrigé : les résultats de `/review` disparaissaient de la timeline juste
après le rendu (le rechargement de la timeline écrasait la carte).

## Compatibilité

- `--pretty` est opt-in ; la sortie par défaut est inchangée.
- `AgentEvent` gagne de nouveaux types d'événements (`system`,
  `assistant_text`, `reasoning`, `tool_use`, `usage`) — additif, sans impact
  sur les consommateurs existants.
- Aucun changement de config ni de schéma de session.
