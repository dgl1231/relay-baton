# v1.3.1 — 데스크톱 핫픽스

**무서명 빌드에서 데스크톱 앱이 아예 안 뜨던 문제 수정** (updater 도입 이후의
모든 MSI/DMG/AppImage). Rust 셸이 Tauri updater 플러그인을 무조건 등록했는데,
릴리즈 워크플로는 updater 서명 secret이 있을 때만 `plugins.updater` 설정을
주입한다 — 그래서 무서명 빌드는 창을 띄우기도 전에 시작 시 패닉했다
(`PluginInitialization("updater", … expected struct Config)`, exit 101).

이제 updater 플러그인은 설정 블록이 있을 때만 등록된다. 서명 빌드는 opt-in
updater를 유지하고, 무서명 빌드는 updater 없이 정상 실행된다.

CLI 변경 없음 — npm/Homebrew/Scoop/Winget 사용자는 영향 없고, 버전만 함께
올라간다. 첫 실제 MSI 설치에서 발견됐다.
