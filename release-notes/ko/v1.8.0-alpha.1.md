# v1.8.0-alpha.1 — 프로젝트 프로필, 인벤토리, 데스크톱 인스펙터

이 alpha는 `v1.8.0-alpha.0`의 workspace map 위에서 v1.8 project-intelligence
라인을 마무리합니다. 모두 결정적·읽기 전용이며 semantic indexing과 모델 호출이
없습니다.

## 추가

- **Project profile 힌트** — `relay-baton profile [--json]`가 workspace map에
  config와 등록된 project 기본값을 결합해 제안합니다: framework 태그, 권장
  build/test 명령(명시적 config 명령이 우선, 없으면 감지된 script + package
  manager에서 파생), diet/agent 기본값, 제외 경로, entry point.
- **Dependency & script 인벤토리** — `relay-baton inventory [--json]`가 package
  script, workspace package(스크립트 포함), CI workflow, release 파일, dependency
  manifest의 bounded 요약을 제공합니다.
- **데스크톱 project inspector** — 읽기 전용 대시보드 "project inspector"
  카드(workspace map + profile)와 Agent Room `/workspace`, `/profile`,
  `/inventory`. 모두 CLI 사이드카 경유.

## 제약

- 결정적·bounded — 알려진 manifest/config만 읽고, 전체 저장소 내용 스캔 없음,
  semantic indexing 없음, 모델 호출 없음.
- 데스크톱 inspector는 CLI 사이드카로만 읽습니다. webview에 비즈니스 로직 없음.
