# v2.4.0-alpha.0 — Smarter handoff (더 똑똑한 핸드오프)

v2.4 "Smarter handoff" — 핸드오프당 토큰을 더 아끼고 로컬 usage를 드러낸다.
모두 결정적이며 임베딩은 없다. 두 로드맵 항목을 이 alpha에서 모두 출하한다.

## 추가

- **Deterministic compaction v2 (결정적 압축 v2).**
  - `SymbolOutline`이 언어별 정규식으로 심볼/헤딩 아웃라인을 추출한다(TS/JS,
    Python, C#, Go, Rust, Java + Markdown 헤딩). repo map에 **"## Symbols
    (changed + key files)"** 섹션이 생겨, 다음 에이전트가 디렉터리 트리뿐 아니라
    구조를 본다.
  - `DiffCompactor.compactRanked`가 diff 청크를 task 관련도(경로 언급, 디렉터리
    근접, source>test>doc 가중치, 얕은 경로 우대)로 랭킹해 가장 관련 있는 파일
    diff가 예산 안에서 먼저 살아남는다. `buildHandoff`가 이를 사용한다.
    lock/build/binary 청크는 맨 아래로 가라앉는다. 임베딩 없음.
- **Local usage insight (로컬 usage 통찰).** `UsageLedger`가 세션별 append-only
  원장(`.ai-session/usage.jsonl`)에 토큰/쿼터 **프록시**(`ceil(chars/4)`,
  진짜 토크나이저 아님)를 기록하고, `run`/`handoff`이 매번 handoff 이벤트를
  남긴다. 신규 `relay-baton usage [--json]`이 합계, 타입·에이전트별 분해,
  handoff 수, 활성 프로파일 대비 budget ratio를 집계한다. **로컬 전용 —
  절대 전송하지 않는다.**

## 하드 제약

변동 없음: local subprocess 전용, 결정적, 직접 LLM API client 없음, 정확한
토크나이저 없음, semantic/vector 인덱싱 없음, 네트워크 없음, 자동
commit/push/PR 없음.
