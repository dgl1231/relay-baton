# v1.5.0 — 데스크톱 앱에서 agent 실행

Agent Room이 뷰어를 벗어난다: 이제 실제로 agent를 실행할 수 있다 —
**확인 후 실행(confirmation-first)**, AGENT_ROOM 설계 문서가 처음부터
명시했던 그대로(preview → confirm → run). 클릭 없이는 아무것도 실행되지
않는다.

## `/run <task>` 와 "여기서 실행"

- 새 **`/run <task>`** composer 커맨드:
  `relay-baton run "<task>" --primary <선택한 agent> --pretty`를 구성 —
  헤더의 Codex/Claude 토글이 이제 실제로 누가 먼저 뛸지 정한다.
- **`/plan`, `/execute`, `/handoff`**도 실제 실행 명령을 구성한다
  (handoff는 `--no-run` 제거).
- 모두 기존 확인 모달에 **정확한 명령**을 보여주고, 새 **"여기서 실행"**
  버튼이 번들 sidecar CLI로 실행한다(내 로컬 agent 로그인/쿼터 사용 —
  relay-baton은 여전히 provider API를 직접 호출하지 않는다). 터미널 복사
  옵션은 그대로.

## 라이브 실행 카드

agent 출력이 타임라인의 라이브 카드로 스트리밍된다(`--pretty` 형식): 도구
호출, assistant 텍스트, 마지막 토큰/비용 영수증이 실시간으로 나타난다.
**취소** 버튼이 프로세스를 종료하고, 끝나면 카드에 초록 `완료` 또는 빨강
`exit N` chip이 붙고 대시보드 패널이 새로고침된다. 동시 실행 1개, 출력은
최근 400줄, 카드는 v1.4.1 결과 카드처럼 타임라인 리로드에서 살아남는다.

## 내부 / 호환성

- Tauri capability 추가: sidecar 범위의 `shell:allow-spawn` +
  취소용 `shell:allow-kill` (execute만으로는 스트리밍 실행이 거부됐을 것).
- GUI는 여전히 business logic 없음: CLI를 spawn하고 줄을 표시할 뿐. 모든
  게이트(handoff 품질, token diet, redaction, guardrail)는 터미널과 똑같이
  CLI 안에서 동작한다.
- 가이드/툴팁 문구를 GUI 4개 언어 전부 갱신 — 이제 "확인 후 실행
  대시보드"이지 read-only가 아니다.
- CLI 동작 변화 없음; 버전은 lockstep으로 범프.
