# v2.0.0-alpha.2 — 데스크톱 계약 + 하드 제약 가드

두 개의 v2.0 안정화 항목을 자동 계약 테스트로 고정합니다. 런타임 동작 변경은
없습니다 — 회귀 방지 가드입니다.

## 추가

- **데스크톱 i18n parity 테스트** — 데스크톱 webview 문자열 테이블이 영어/한국어/
  일본어/중국어(간체)에서 정확히 같은 키 집합을 갖는지(누락·초과·중복 없음), 그리고
  HTML에서 쓰는 모든 `data-i18n*` 키가 존재하는지 강제합니다. "안정적인 데스크톱
  계약"(project 관리·status/budget·git·session archives·replay·handoff preview·
  guarded execution·project inspector·team handoff)이 이제 가드됩니다.
- **하드 제약 테스트** — auth 정책(provider key env 차단, `allowApiKeyEnv` off,
  cli-session 모드)을 고정하고, 어떤 패키지도 직접 LLM API client 의존성을 선언하지
  않음을 검증합니다.

## 제약 (재확인)

- LLM API 직접 호출 없음, API key 저장 없음, 자동 commit/push/PR 없음, daemon 요구
  없음, 실시간 chat 플랫폼 없음, 기본 semantic/vector indexing 없음. 결정적·
  local-first·subprocess-only.

## v2.0 다음 항목

- installer/update 스토리 확정; 공개 문서 패스.
- breaking change가 필요할 때 아티팩트별 schema v2 bump.
