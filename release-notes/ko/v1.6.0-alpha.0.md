# v1.6.0-alpha.0 — 세션 아카이브, 복구 진단, 데스크톱 탐색

이 alpha는 v1.6 세션 아카이브 라인을 마무리합니다. 이제 아카이브를 나열·검사하고
복구 진단을 받을 수 있으며, 읽기 전용 데스크톱 패널까지 제공합니다. 모두 결정적이고
읽기 전용이며 자동 복원은 없습니다.

## 추가

- `relay-baton session list [--json] [--out <dir>]` — 보관된 세션을 최신순으로
  나열합니다. 각 `manifest.json`을 읽어 id, file 수, 총 bytes, `createdAt`을
  보고하고, manifest가 없거나 깨진 아카이브는 표시하며, 아카이브 루트가 없으면
  깔끔하게 degrade합니다.
- `relay-baton session inspect <archive> [--json] [--out <dir>]` — 아카이브
  하나를 manifest 기준으로 검증합니다. file별 존재 + size + SHA-256을 확인하고
  `missing`/`corrupt`/`intact`로 요약합니다. 복사/복원은 하지 않습니다.
- `relay-baton session resume [--json] [--stale-hours <n>]` — 현재
  `.ai-session`을 진단(missing/incomplete/stale/ok)합니다. 필수 파일 존재 여부,
  `session.json` 유효성, git baseline drift, `updatedAt` 경과시간을 보고 가장
  안전한 다음 명령(`init`, `status`, `replay`, `review`, `handoff`,
  `session archive`)을 제안합니다.
- 데스크톱 대시보드에 **세션 아카이브** 카드와 Agent Room `/sessions`,
  `/inspect <id>`, `/resume` 추가 — 모두 CLI 사이드카 경유의 읽기 전용입니다.

## 변경

- `docs/COMMANDS.md`, `docs/i18n/COMMANDS.ko.md`에 새 명령을 문서화했습니다.
- `docs/ROADMAP.md`, `docs/TASK-v1.6-session-archives.md`, `docs/HANDOFF.md`에
  v1.6 acceptance 항목을 모두 완료로 표시했습니다.

## 제약

- 읽기 전용: list/inspect/resume는 복사/적용/복원/prune을 하지 않습니다.
- 데스크톱 패널은 CLI 사이드카로만 읽습니다. webview는 아카이브 디렉터리나
  `.ai-session`을 직접 건드리지 않습니다.
- 자동 복원 없음, 클라우드 업로드 없음, 파괴적 prune 없음. 결정적 동작만 하며
  모델 호출이 없습니다.
