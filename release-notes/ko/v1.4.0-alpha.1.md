# v1.4.0-alpha.1 — 배포 polish hotfix

이 alpha는 v1.4 배포 polish 범위를 유지하면서 `v1.4.0-alpha.0`에서 발견된 macOS release 경로를 고친 버전입니다.

## 수정됨

- Apple 서명 secret이 모두 설정된 경우에만 macOS desktop release build에 Apple signing env를 전달합니다.
- Apple 서명 secret이 없으면 빈 인증서를 import하려고 하지 않고 unsigned/ad-hoc desktop build 경로로 진행합니다.

## v1.4.0-alpha.0 포함 내용

- SHA-256 검증을 포함한 Linux/macOS 및 Windows CLI one-line installer.
- release `SHA256SUMS` 및 best-effort CycloneDX SBOM 생성.
- Homebrew formula와 Scoop manifest starter 파일.
- Azure Artifact Signing 기반 Windows MSI 선택 서명 hook.
- desktop 앱의 Codex/Claude command preview agent switcher.
