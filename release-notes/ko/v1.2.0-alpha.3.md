# v1.2.0-alpha.3 — Desktop project 관리 + i18n

alpha.2의 sidecar 수정 뒤 요청된 desktop 후속 기능이다. GUI에서 project를 직접
관리할 수 있고, 앱 UI 언어를 바꿀 수 있다.

## 추가

- **Desktop GUI project 관리** — native folder picker 또는 직접 경로 입력으로
  project를 추가하고, active project를 전환하며, 선택 project를 명시적 확인 후
  제거한다. 등록만 할 때는 project 폴더가 git repository일 필요가 없다. webview는
  여전히 bundled CLI sidecar만 호출한다.
- **GUI용 CLI JSON 계약** — `project add --json`은 `{ added, project }`,
  `project remove --json`은 `{ removed }`를 출력한다.
- **Desktop UI i18n** — UI chrome은 영어(기본), 한국어, 일본어, 중국어 간체를
  지원한다. 패널에 표시되는 CLI 출력은 번역하지 않고 원문 그대로 둔다.

## 비고

- 새 folder picker는 Tauri dialog plugin을 사용한다. stable v1.2 태그 전 각
  대상 OS의 실제 Tauri 창에서 권한과 동작을 확인해야 한다.
- 기존 제약은 그대로다: 직접 model API 호출 없음, API key 저장 없음, 자동
  commit/push/PR 없음, GUI에서 agent 실행 없음.
