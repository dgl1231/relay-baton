# v1.2.0-alpha.2 — Desktop sidecar 수정 (GUI가 실제로 CLI와 통신)

`v1.2.0-alpha.1`의 첫 실제 창 테스트에서 앱은 정상 실행됐지만(레이아웃·테마·
아이콘·단축키) 모든 패널이 *"Not running inside Tauri."*에 멈춰 있었다 — webview가
CLI sidecar에 접근하지 못했다. 이 릴리스가 그걸 고친다.

## 수정

- **Webview가 Tauri API를 로드하지 못함.** 프런트엔드가 번들러 없는 정적 HTML이라
  bare ES-module 지정자(`@tauri-apps/plugin-shell`, `@tauri-apps/api/window`)가
  webview에서 해석되지 않았고, sidecar 호출이 조용히 "not inside Tauri" 메시지로
  떨어졌다. 수정:
  - `tauri.conf.json` → `app.withGlobalTauri: true`로 core + plugin API를
    `window.__TAURI__`에 노출.
  - `ui/index.html`이 동적 import 대신 `window.__TAURI__.shell.Command`(sidecar)와
    `window.__TAURI__.window.getCurrentWindow()`(종료)를 사용.

이로써 status / budget / handoff 패널, 프로젝트 스위처, 대화 타임라인, 읽기 전용
액션 버튼(`review`, `diagnose`, `status`)이 의도대로 번들된 CLI와 통신한다.

## 비고

- CLI 동작 변화 없음. 인스톨러는 여전히 미서명(Windows)/ad-hoc(macOS); GUI는
  읽기 전용 / confirmation-first 유지.
