# v1.1.2 — 릴리즈 파이프라인 핫픽스 (번들러 PATH)

패치 릴리즈. 동작 변경 없음 — OS별 단일 실행파일이 실제로 빌드되도록 **릴리즈
워크플로**를 두 번째로 고친다.

## 수정

- **`release.yml` — `npx --yes esbuild/postject`가 exit 127로 실패.** v1.1.1로
  워크플로가 유효한 YAML이 된 뒤 3개 매트릭스 잡이 전부 실행됐지만, `npx --yes
  <tool>`이 CI 러너에서 도구 bin을 PATH에 안정적으로 노출하지 못해
  (`command not found`) 실패했다. 이제 `npm install -g esbuild postject`로 명시적
  설치 후 직접 호출한다 — 로컬에서 end-to-end로 검증한 레시피(esbuild → SEA blob →
  node 복사 → postject 주입 → codesign → `--version` smoke test)와 동일하다.
  글로벌 npm 저장소만 건드리고 저장소 lockfile은 안 바꾸므로 build/test CI는
  그대로 통과한다.
