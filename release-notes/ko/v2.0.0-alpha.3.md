# v2.0.0-alpha.3 — installer/update 확정 + 공개 문서 패스

v2.0 안정화 항목 두 개를 더 마무리합니다. 문서·정책만 변경, 런타임 변경 없음.

## 추가

- **확정된 배포 & 업데이트 정책** — `docs/RELEASE.md`에 잠긴 v2.0 정책을 명시:
  모든 릴리즈는 항상 CLI 바이너리 3종, 데스크톱 인스톨러 3종, `SHA256SUMS`,
  CycloneDX SBOM을 출하한다. 서명(macOS/Windows)과 opt-in·수동 데스크톱 updater
  채널은 repo secret이 있을 때만 조건부. one-line 인스톨러는 설치 전에
  `SHA256SUMS`를 검증한다.
- **통합 공개 가이드** — `docs/GUIDE.md`(EN)와 `docs/i18n/GUIDE.ko.md`(KO)가 설치,
  빠른 시작, 데스크톱 + CLI 워크플로, 프로젝트 registry, 아티팩트/스키마, 안전
  모델을 다루며 README에서 링크된다.
