# v1.1.3 — 릴리즈 파이프라인 핫픽스 (번들러 버전 고정)

패치 릴리즈. 동작 변경 없음 — OS별 단일 실행파일이 실제로 빌드되도록 **릴리즈
워크플로**를 세 번째이자 마지막으로 고친다.

## 수정

- **`release.yml` — `npm install -g esbuild@^0.21 postject@^1`가
  `ETARGET / No matching version found for postject@^1`로 실패.** `postject`의
  배포된 "latest"가 프리릴리즈(`1.0.0-alpha.6`)이고, caret 범위는 프리릴리즈를
  제외하므로 `^1`이 아무것도 못 찾아 3개 매트릭스 잡이 설치 단계에서 전부 실패했다.
  이제 로컬에서 end-to-end로 검증한 정확한 버전을 고정한다:
  `esbuild@0.28.0`, `postject@1.0.0-alpha.6`.

## 진행 경과 (기록용)

- v1.1.0 — YAML 오류(115줄 `&` 앵커); job 미실행.
- v1.1.1 — YAML 유효, 3 job 실행됐으나 `npx --yes`가 bin 노출 실패(exit 127).
- v1.1.2 — `npm install -g`로 전환했으나 잘못된 버전 범위(`postject@^1`).
- v1.1.3 — 정확한 버전 고정. ✅
