# v2.2.0-alpha.0 — Trust & supply chain (신뢰 · 공급망)

v2.2 "Trust & supply chain" — 외부에서 받은 아티팩트와 우리 릴리즈를 신뢰
가능하게 만든다. 세 로드맵 항목을 이 alpha에서 모두 출하한다.

## 추가

- **신뢰 불가 번들 / path-traversal 안전.** handoff 번들·세션 아카이브의
  `inspect`가 더 이상 manifest의 `target` 경로를 신뢰하지 않는다. 공유 가드
  `resolveWithin`(`@relay-baton/shared`)이 절대경로, `..` 탈출, 심링크 탈출을
  거부하고, 파일별 크기 상한(`MAX_INSPECT_FILE_BYTES`, 8 MiB)으로 검증 읽기를
  제한한다. 거부된 항목은 새 `unsafe[]`로 분류(읽지 않음)되고, 각 파일에
  `safe`/`unsafeReason`가 붙으며, 결과에 최상위 `safe` 플래그가 노출된다 — CLI는
  `trust: safe | UNSAFE — do not import`을 출력한다. Bundler/archiver는 이제
  번들 상대 POSIX target을 기록해 정상 아티팩트가 가드를 통과한다.
- **서명 릴리즈 + provenance (기본 활성).** 릴리즈 파이프라인이
  `actions/attest-build-provenance`로 모든 CLI 바이너리 + `SHA256SUMS`에 SLSA
  build provenance를 게시한다. 기본 `GITHUB_TOKEN`을 쓰므로 추가 secret 없이
  기본 활성이다. 다운로드 검증:

  ```bash
  gh attestation verify relay-baton-linux-x64 --repo dgl1231/relay-baton
  ```

  기존 secret 기반 Azure/Apple/Tauri 코드 서명은 설치 파일에 그대로 적용된다.
- **공급망 하드닝.** `ci.yml`/`release.yml`의 모든 GitHub Action을 commit SHA로
  핀(버전 주석 동반)했고, `.github/dependabot.yml`이 npm(root+desktop)·cargo
  (Tauri)·github-actions에 대해 주간 그룹 업데이트 PR을 연다. 또한
  `release-finalize`가 `.github/scripts/sbom-diff.mjs`로 이전 릴리즈 대비
  CycloneDX SBOM diff(추가/제거/변경 컴포넌트)를 만들어 `sbom-diff.md`로
  게시한다(advisory).

## 하드 제약

변동 없음: local-first, subprocess-only, deterministic, 직접 LLM API client 없음,
자동 commit/push/PR 없음. inspect는 여전히 read-only.
