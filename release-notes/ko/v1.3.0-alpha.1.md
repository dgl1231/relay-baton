# v1.3.0-alpha.1 — Desktop Agent Room UX 개편

v1.3 Agent Room 위에 실제 창 UX 작업을 한 차례 더했다. CLI 동작은 변화 없고, 모두
sidecar 위에서 읽기 전용 / confirmation-first를 유지한다.

## 추가 / 변경 (데스크탑)

- **탭 레이아웃** — 창을 **대시보드**(status + budget 패널)와 **Agent Room** 탭으로
  분리. 창이 전체 높이라 Agent Room의 대화 타임라인이 고정 박스 대신 화면을 꽉
  채운다. 마지막 탭 기억.
- **압축 컨텍스트 스트립** — Agent Room 상단(프로젝트 · 세션 · status · budget%)으로
  큰 패널 없이 맥락 유지.
- **handoff 모달화** — 헤더 버튼 또는 `h` 단축키로 열고, 읽기 전용, Close / 배경 /
  Esc로 닫힘.
- **슬래시 명령 팔레트** — 입력창에 맨 앞 `/`를 치면 명령 목록이 입력창 위로 뜨고,
  각 설명과 함께 입력에 따라 필터링.
- **버튼 정리** — 중복되던 상단 액션 줄 제거; 입력창 아래 슬래시 힌트 버튼에 호버
  툴팁(읽기 전용 vs 미리보기) 추가.
- **`?`가 사용법 가이드로** — 단축키뿐 아니라 탭/프로젝트/Agent Room 명령/handoff/
  diet/언어/테마 설명 섹션 포함. 전부 번역.

## 비고

- 읽기 전용 명령(`/status`, `/budget`, `/review`, `/diagnose`, `/replay`)은
  sidecar로 실행; `/plan`, `/execute`, `/handoff`는 미리보기만 — GUI는 agent를
  실행하지 않음.
- 모든 UI는 English / 한국어 / 日本語 / 中文 번역. 인스톨러는 여전히 미서명
  (Windows) / ad-hoc 서명(macOS).
