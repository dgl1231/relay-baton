# v2.0.0-alpha.6 — conversation 스키마 + 세션 export; v2.0 feature-complete

남은 v2.0 / v1.6 항목을 마무리하고 다음 라인 로드맵을 기록합니다.

## 추가

- **conversation 이벤트를 버전드 스키마 계약에 편입** — 이벤트가 이제
  `schemaVersion`을 가지며(append 시 stamp), `conversation`이
  `ARTIFACT_SCHEMA_VERSIONS`에 등록되고, `relay-baton migrate` / `doctor --deep`가
  legacy `conversation.jsonl`을 다른 버전드 아티팩트처럼 감지/정규화한다.
- **`relay-baton session export <archive> --to <dir> [--overwrite]`** — 보관된
  세션을 공유/백업용으로 대상 위치에 복사한다. 아카이브는 읽기 전용이며
  `--overwrite` 없이는 덮어쓰지 않는다.

## 문서

- ROADMAP: 계획된 v1.x/v2.0 항목이 모두 `[x]`. **"Beyond v2.0 — proposed"** 섹션
  추가: 기능 추가(멀티 agent 매트릭스, N-way relay, 결정적 compaction v2, bounded
  `run --until`, project recipe, 로컬 usage insight)와 하드닝(Windows spawn 신뢰성,
  handoff 전 redaction, 신뢰 불가 번들/path-traversal 안전, 서명 릴리즈 + provenance,
  공급망 하드닝, secret 유출 회귀 스캔) — 모두 기존 하드 제약 내, 아직 미확정.

## v2.0 현황

Feature-complete. 아티팩트 schema-v2 라인 완비(레지스트리 + inspector + migrator가
session.json, checkpoints, git-baseline, conversation 커버). 향후 버전 bump은 같은
레지스트리에 migrator를 붙인다.
