# v1.5.0-alpha.0 — Git tracking first cut

이 alpha는 v1.5 git tracking 작업의 첫 버전입니다.

## 추가됨

- 읽기 전용 `relay-baton git status` 및 `relay-baton git status --json` 추가: branch, ahead/behind, clean/dirty, staged/unstaged/untracked, changed file, diff stat 요약.
- non-git 프로젝트는 실패하지 않고 git tracking을 `available:false`로 표시합니다.
- Desktop Dashboard에 CLI sidecar 기반 Git 패널을 추가했습니다.
- Agent Room에서 읽기 전용 `/git` 명령을 지원합니다.
- `init` 시 `.ai-session/git-baseline.json`을 생성하고, `git status --json`이
  그 baseline 이후 branch, HEAD, dirty 상태 변화 여부를 보고합니다.
- `status --json`, `review --json`, 생성된 handoff에 bounded git tracking
  요약을 포함합니다. full diff는 계속 파일 참조로만 유지합니다.
- `docs/TASK-v1.5-git-tracking.md`에 v1.5 계획과 carry-over를 기록했습니다.

## 제약

- git 쓰기 명령은 추가하지 않았습니다. commit, push, PR, branch, checkout, reset, merge, stash 자동화는 없습니다.
