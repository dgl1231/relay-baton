# v1.4.0-alpha.0 — 배포 polish

이번 alpha는 v1.4 배포 hardening 작업의 시작이다. 기존 안전 모델은 유지한다.
desktop 앱은 계속 sidecar-only / confirmation-first이고, signing secret이 없어도
unsigned fallback build는 계속 동작한다.

## 변경사항

- one-line CLI installer 추가:
  - macOS/Linux: `install/install.sh`
  - Windows: `install/install.ps1`
- installer는 최신 release binary를 받고, `SHA256SUMS`로 검증한 뒤, 관리자
  권한 없이 설치하고 PATH/다음 단계 안내를 출력한다.
- release finalization metadata 추가:
  - release asset 전체에 대한 `SHA256SUMS`
  - best-effort CycloneDX SBOM (`relay-baton.cdx.json`)
- package-manager starter 파일 추가:
  - `scoop/relay-baton.json`
  - `homebrew/relay-baton.rb`
- optional signing hook 연결:
  - Azure signing secret이 있으면 Windows MSI를 Azure Artifact Signing으로 서명.
  - Apple Developer secret이 있으면 Tauri macOS signing/notarization env를 전달.
- desktop에 Codex/Claude target-agent switcher 추가. `/plan`, `/execute`,
  `/handoff` 미리보기 명령에만 반영되며 agent를 실행하지 않는다.

## 호환성

- 기존 수동 다운로드 방식은 계속 동작한다.
- installer는 `SHA256SUMS`가 필요하므로 이번 release 이후 자산에 맞춰 사용한다.
- `scoop/`과 `homebrew/` 파일은 현재 최신 alpha를 기준으로 하며, release 시
  hash bump 대상이다.
- v1.3 stable 승격은 Rust/toolchain이 있는 머신에서 real-window QA가 아직 필요하다.

## 안전

- 직접 LLM API 호출 없음.
- API key 저장 없음.
- auto commit, auto push, auto PR, daemon, silent desktop updater 없음.
- desktop agent 선택은 미리보기 명령에만 영향을 주는 display/pass-through 기능이다.
