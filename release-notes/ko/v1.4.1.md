# v1.4.1 — 데스크톱 타임라인 다듬기

v1.4.0 데스크톱 앱을 실사용하다 발견한 Agent Room 타임라인 QoL 수정 2건.
데스크톱 전용 — CLI 동작 변화 없음, 버전은 lockstep으로 범프.

## 결과 카드가 타임라인 리로드에서 살아남음

v1.4.0에서는 슬래시 커맨드의 결과 카드가 다음 커맨드의 타임라인 리로드와
동시에 사라져서, 항상 마지막 카드 하나만 보였다(원래 있던 동작이지만 결과가
카드가 되면서 훨씬 눈에 띄게 됨). 이제 로컬 결과 카드를 메모리에 보관하고
리로드 때마다 타임스탬프 순으로 타임라인에 다시 병합한다 — 커맨드를 연달아
쳐도 읽을 수 있는 히스토리가 남는다. 프로젝트 전환 시에는 비우고(이전
프로젝트 얘기니까), 최근 50개까지 유지한다.

## 역할별 색상 구분 타임라인

user와 relay-baton 이벤트가 같은 배경·같은 테두리로 렌더링돼 대화가 뭉개져
보였다. 이제 행이 화자별로 색 구분된다:

- **user** — 파란 왼쪽 보더 + 밝은 배경, 커맨드는 monospace
- **relay-baton** — 앰버 왼쪽 보더
- **claude** / **codex** — 각자의 agent 색 (헤더 토글과 동일)

다크/라이트 테마 모두 지원.
