# v1.2.0-alpha.1 — Desktop GUI 프리릴리스 (MSI 핫픽스 + Phase D)

데스크탑 프리릴리스를 완성한다. `v1.2.0-alpha.0`은 6개 중 5개만 빌드됐고(Windows
`.msi`만 실패), 이 태그가 전체 세트를 다시 만들고 Phase D 폴리시를 포함한다.

## 수정

- **Windows `.msi` 빌드 실패** — *"optional pre-release identifier in app version
  must be numeric-only … for msi target"*. WiX/MSI는 앱 버전으로 `1.2.0-alpha.0`을
  거부한다(`.dmg`/`.AppImage`는 허용). 이제 데스크탑 앱 버전(`tauri.conf.json`)을
  plain `1.2.0`으로 두고, prerelease 식별은 git 태그/릴리스명에만 둔다.
  (RELEASE.md gotcha #5.)

## 추가 (Phase D)

- **코드 서명 & 공증 문서화** — `docs/RELEASE.md`: 현재 ad-hoc(macOS)/미서명
  (Windows) 상태, Gatekeeper / SmartScreen 우회법, 실인증서 경로.
- **창 상태 영속화** — `tauri-plugin-window-state`로 창 크기/위치 기억.
- **라이트/다크 테마 토글** — CSS 변수 기반, `localStorage` 저장.
- **키보드 단축키** — Ink TUI 미러링: `r` 새로고침, `p` 다음 프로젝트, `d` diet
  순환, `b` budget, `h` handoff, `t` 테마, `q` 종료, `?` 도움말.

## 비고

- 인스톨러는 여전히 미서명(Windows)/ad-hoc 서명(macOS) — SmartScreen / Gatekeeper
  경고 발생 가능. GUI는 읽기 전용 / confirmation-first.
