# v1.1.1 — 릴리즈 파이프라인 핫픽스

패치 릴리즈. 동작 변경 없음 — OS별 단일 실행파일이 실제로 빌드되어 GitHub
Release에 첨부되도록 **릴리즈 워크플로**를 고친다.

## 수정

- **`.github/workflows/release.yml` 115번 줄 — 잘못된 YAML.** Windows smoke-test
  스텝이 `& "dist-bin/..." --version`를 한 줄로 실행했는데, YAML은 맨 앞의 `&`를
  앵커로 해석한다. 그래서 워크플로 파일 자체가 파싱에 실패하고
  (*"Invalid workflow file … line 115"*) v1.1.0 태그에서 **job이 하나도 실행되지
  않았다** — v1.1.0이 자동 생성 소스 아카이브만 있고 바이너리가 없던 이유다.
  이제 리터럴 블록 스칼라로 감쌌다.

## 새 태그를 쓰는 이유

릴리즈 워크플로는 **태그 커밋 시점의 `release.yml`** 사본으로 실행된다. v1.1.0
태그는 수정 이전이라, 고친 워크플로로 파이프라인을 다시 돌리는 깔끔하고 비파괴적인
방법은 새 `v1.1.1` 태그다.

release" 다운로드 링크는 자동으로 이걸 가리킨다.
