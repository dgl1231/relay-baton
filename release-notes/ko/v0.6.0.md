# relay-baton v0.6.0 릴리즈 노트

상태: **Released**

날짜: 2026-05

테마: **Trust & Verify** — 새 surface를 늘리기 전에, 기존 파이프라인을
증명 가능하고 관찰 가능하게 만든다. 신규 workflow mode 없음. 모든 변경은
additive하며 backward compatible.

## 요약

v0.6은 v0.4/v0.5가 만든 것을 견고하게 한다. 이제 모델 토큰을 한 톨도 쓰지
않고 harness가 올바르게 연결됐음을 *증명*할 수 있다: `verify`는 simulated
end-to-end 검증을 돌리고, `doctor --deep`은 OK/WARN/FAIL 진단 체크리스트를
제공한다. TUI는 현재 workflow mode와 plan/compression 상태를 한눈에 보여준다.

## 추가 (Added)

- **`relay-baton verify`** — 기본적으로 **실제 모델 호출 없이** 도는 simulated
  end-to-end 검증. 검증 항목: repoRoot 해석, `doctor` core 체크, fallback
  문구 감지(실제 문구는 감지, grep/결과형 라인은 무시), handoff no-run
  workflow(실제 `.ai-session/`을 건드리지 않고 임시 repo 사용), token budget
  준수, API key env 차단. 실패 시 non-zero 종료.
  - 옵션: `--project`, `--path`, `--diet`, `--real-agents`, `--keep-temp`,
    `--verbose`.
  - `--real-agents`는 **experimental scaffold 전용**이며 실제로 실행되지 않는다.

- **`relay-baton doctor --deep`** — core 체크 위에 확장 진단: Node/pnpm 버전,
  adapter args 점검(`--full-auto` / `--ask-for-approval` / `bypassPermissions`
  같은 금지 인자는 failure로 표시), Windows에서 `.gitattributes`/CRLF 힌트,
  project registry 상태, `.ai-session/` 상태, 최신 handoff budget / `plan.md`
  상태 / compression(rotated log) 상태. **API key 값은 절대 출력하지 않고**
  존재 여부만 표시한다.

- **TUI mode 패널** — dashboard가 현재 mode(idle/run/handoff/plan/execute/
  compress-context), 최신 plan 상태, 최신 compression 상태, 최신 handoff 정보를
  표시한다. 표시 전용 — TUI는 여전히 agent를 절대 실행하지 않는다.

## 변경 (Changed)

- `doctor` 출력을 Core / Deep / Summary 섹션으로 재구성하고 pass/warn/fail
  집계를 표시한다. hard failure에서만 non-zero 종료.
- CLI 버전을 `0.6.0`으로 bump.

## 문서 (Docs)

- 신규 `docs/ROADMAP.md`: v0.6(Trust & Verify), v0.7(Review & Diagnose),
  v0.8(Adapter Expansion), v0.9(Automation & Runtime), v1.0(Stable Local
  Release).
- README에 plan-execute / context-compression workflow 설명과 verification
  명령 모음 섹션 추가.

## 테스트 (Tests)

- `diagnostics.test.ts` — core/deep 체크, 금지 인자 감지, API key 값 미출력 보장.
- `verify.test.ts` — simulated 파이프라인 exit 0 통과, cwd의 `.ai-session/`에
  쓰지 않음, `--real-agents` 비실행 확인.
- `docs.test.ts` — ROADMAP과 v0.6 릴리즈 노트(EN+KO) 존재, README의
  plan/execute/compress-context/verify 문서화 확인.

## 미포함 (여전히 보류)

- Plan execution receipts, plan diffing, multi-turn loop → **v0.7+**.
- Adaptive per-model threshold, cross-session 압축 → **v0.9**.
- OpenCode / Gemini / Aider adapter → **v0.8**, 필요 시.
- Semantic summarization, exact tokenizer, 자동 commit/push/PR — 영구 out of
  scope.

## 업그레이드 노트

- 완전 additive. config migration 불필요. 신규 CLI 플래그는 optional.
- `verify`와 `doctor --deep`는 네트워크/모델 호출이 없고 repo에 아무것도 쓰지
  않는다(verify는 정리되는 OS 임시 디렉터리 사용).

## 검증 명령

```bash
pnpm build
pnpm test
relay-baton doctor
relay-baton doctor --deep
relay-baton verify
relay-baton verify --project relay-baton
relay-baton handoff --to claude --no-run --diet caveman
relay-baton budget
relay-baton project current
```

위 명령 중 실제 Codex/Claude 모델을 호출하는 것은 없다.
