# v1.8.0-alpha.0 — Workspace map v2

이 alpha는 v1.8 project-intelligence 라인을 결정적·bounded workspace map으로
시작합니다. semantic indexing 없음, embedding 없음, 모델 호출 없음.

## 추가

- **Workspace map v2** — `relay-baton workspace [--json]`가 manifest/config
  파일에서 바로 저장소의 구조적 map을 만듭니다:
  - 감지된 package manager(pnpm, npm, yarn, cargo, go, pip, bundler, dotnet),
  - 언어(typescript, javascript, rust, go, python, ruby, csharp),
  - monorepo 패키지(pnpm-workspace.yaml 또는 `workspaces`, bounded),
  - npm script(build / test / lint + 기타),
  - entry point(package.json main/module/bin, 일반적인 src 진입점),
  - docs(README, docs/, CONTRIBUTING, CHANGELOG),
  - AGENTS / CLAUDE / .cursorrules 파일.

## 제약

- 결정적·bounded — 알려진 manifest/config만 읽고, 전체 저장소 내용 스캔 없음,
  semantic indexing 없음, 모델 호출 없음.
- 읽기 전용.

## v1.8 다음 항목

- Project profile hints(command 기본값, 제외 경로, 언어 태그).
- Dependency / script inventory.
- Desktop project inspector(읽기 전용, CLI 사이드카 경유).
