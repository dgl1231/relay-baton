# v1.5.1 — 정직한 실행 종료 & 조용해진 라이브 출력

v1.5.0 "데스크톱 앱에서 agent 실행"의 작은 후속 2건. 둘 다 실기기에서
실제 `/run`을 검증하다 발견했다.

## 실패 종료를 이제 구분할 수 있다

relay chain이 **실행됐지만 non-zero로 종료한** agent에서 끝나도 `run`(과
`execute`)이 여전히 `0`으로 종료했다. 데스크톱 앱에서는 스트리밍 출력이
`✗ <agent> exited with code N`으로 끝났는데도 실행 카드에 초록 `완료`
chip이 떴다. 이제 그런 종료는 **`4`**로 종료하므로, 실행 카드가 chip을
빨간색으로 표시하고 스크립트도 실패 종료와 정상 종료를 구분할 수 있다.

`run`/`execute` 종료 코드 전체: `0` 성공 · `1` agent spawn 실패 ·
`2` 사용 오류 · `3` quality gate가 handoff 차단 · `4` 체인이 실패한 agent
에서 끝남.

## 조용해진 라이브 실행 카드

Claude는 턴 중간에 일상적인 `rate_limit_event` 텔레메트리 줄을 내보낸다.
이건 인식되는 이벤트가 아니라 그동안 라이브 카드에 raw로 통과됐다. 이제
화면에서는 숨긴다(raw 줄은 여전히 fallback 감지와 디스크 로그에 도달 —
손실 없음).

## 호환성

- 새 명령/플래그 없음; 외부 동작 변화는 종료 코드 `4` 하나뿐.
- 데스크톱과 CLI 버전은 lockstep으로 범프.
