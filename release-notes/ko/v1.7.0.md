# v1.7.0 — 모델 선택, 모델 간 fallback

이제 각 agent CLI가 **어떤 모델**로 실행될지 고를 수 있고, agent 사이뿐 아니라
같은 agent의 모델 사이에서도 baton을 넘길 수 있다.

## 무엇이 바뀌었나

- `run`, `plan`, `execute`, `handoff`에 **`--model <id>`** 추가. agent CLI의
  모델 플래그(`codex exec -m`, `claude --model`, `gemini -m` …)로 전달된다.
  id는 자유 입력이라 이후 나오는 신규 모델도 업데이트 없이 쓸 수 있다.
- config에 **agent별 기본 모델** `agents.<id>.model` 지원
  (예: `"claude": { …, "model": "claude-opus-5-5" }`). 없으면 지금처럼 CLI 기본값.
- **같은 agent 내 모델 fallback.** 체인 항목에 `agent:model` 사용 가능:
  `relay-baton run "…" --chain claude:claude-opus-5-5,claude:claude-sonnet-5,codex`
  — 첫 모델이 한도에 걸리면 agent를 바꾸기 전에 같은 CLI의 다음 모델로 넘긴다.
- **데스크톱 모델 선택기**(Codex/Claude 스위치 옆): 최신 모델 추천
  (GPT-6.1 Sol / GPT-6 Astra / GPT-6 Luna, Claude Opus 5.5 / Sonnet 5 / Fable 5.1 /
  Haiku 4.5) 또는 직접 입력. 비우면 CLI 기본값. agent별로 기억된다.
- **fallback 감지 확대:** `overloaded_error`, `resource_exhausted`,
  `credit balance is too low`, `context window exceeded`, codex의
  "You've hit your usage limit" 문구.
- `session.json`에 `activeModel`(요청한 모델)과 `reportedModel`(`--pretty`일 때
  claude가 보고한 실제 모델) 기록. handoff에는 이전/다음 hop이 `agent:model`로 표시된다.

## 호환성

- 순수 추가 기능. `--model`/`agents.<id>.model`이 없으면 v1.6.x와 완전히 같은
  명령이 실행된다. config/session 스키마는 선택 필드만 늘었다.
