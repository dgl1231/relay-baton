# v1.0.0 — 정식 출시 (GA)

첫 공개 정식 출시(GA). relay-baton이 영구 `-alpha.N` 라인을 졸업한다. 직전 alpha
대비 기능 변경은 없으며, 이 릴리즈는 프로젝트를 **법적으로 사용 가능하고 설치
가능**하게 만든다.

> 이 문서는 `v1.0.0` 태그의 **GA** 노트다. 이전
> [`v1.0.0.md`](./v1.0.0.md)는 GA 이전 "Stable Local Release" 마일스톤을
> 기록한 것으로, 히스토리 보존용으로 남겨둔다.

## 추가

- 저장소 루트에 **MIT `LICENSE`** (이전엔 미라이선스 = "all rights reserved").
  모든 패키지 매니페스트에 `license: "MIT"`.
- **npm 배포** — CLI는 **`@relay-baton/cli`**로 배포되며(익숙한 `relay-baton`
  명령 설치), 공개 라이브러리 `@relay-baton/core`·`shared`·`tui`도 함께.
  clone 없이 `npm i -g @relay-baton/cli` / `npx @relay-baton/cli` 동작.
- **패키지 매니저** — Homebrew tap(`dgl1231/homebrew-relay-baton`), Scoop
  bucket(`dgl1231/scoop-relay-baton`), Winget(`dgl1231.relay-baton`).
- **`CHANGELOG.md`** + 태그 하나로 전 채널(npm/Homebrew/Scoop/Winget) 자동 배포하는
  릴리즈 파이프라인.

## 변경

- 전 패키지 **1.0.0**로 버저닝; GA 버저닝이 `-alpha.N`을 대체.

## 하드 제약 (불변, 테스트로 고정)

- OpenAI/Anthropic API 직접 호출 없음; 로컬 `codex`/`claude` CLI subprocess 전용.
  API key 저장/출력 없음. 자동 commit/push/PR 없음; 데몬 없음; 결정적 압축만.
