# v1.9.0-alpha.0 — 팀 handoff 패키지

이 alpha는 local-only 안전 모델을 유지하면서 relay-baton 아티팩트를 다른 사람이나
로컬 agent 환경과 쉽게 공유할 수 있게 합니다. 모두 결정적이고 저장소에 대해 읽기
전용이며, 모델 호출과 클라우드 업로드가 없습니다.

## 추가

- **Portable handoff 번들** — `relay-baton handoff bundle [--json] [--dry-run]
  [--out <dir>]`이 큐레이션된 `.ai-session` 아티팩트(handoff, compact state, repo
  map, plan + receipts, decisions, changed files, test results, errors,
  session.json)와 git 요약을 timestamp 번들로 묶고 `manifest.json`(파일별 size +
  SHA-256)을 씁니다.
- **Redaction 패스** — 명백한 secret, API key, 절대 home 경로, 과대 파일에 대한
  결정적 스캔이 모든 번들에서 실행되어 `redaction.json`에 기록되고 `handoff
  bundle`에서 경고로 표시됩니다.
- **Import / inspect** — `relay-baton handoff inspect <bundle> [--json]`이
  manifest와 파일별 무결성(존재 + size + SHA-256)을 검증하고 번들 내용을
  출력합니다. 아무것도 적용하지 않습니다.
- **마크다운 리포트** — `relay-baton report [--out <file>] [--json]`이 기존
  아티팩트로 사람이 읽는 상태 리포트(task, status, git, 실행 체크포인트, handoff
  발췌)를 생성합니다. PR 코멘트/이슈/팀 챗용.
- **데스크톱 export 플로우** — 읽기 전용 "team handoff" 대시보드 카드(번들 생성,
  리포트 복사)와 Agent Room `/bundle`, `/report`. 모두 CLI 사이드카 경유.

## 제약

- 결정적·소스 저장소 읽기 전용; 번들은 번들 디렉터리에만 씁니다.
- 클라우드 업로드 없음, 모델 호출 없음. 데스크톱 플로우는 CLI 사이드카로만
  동작하며 webview에 비즈니스 로직이 없습니다.
