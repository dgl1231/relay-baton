# v1.3.0 — 라우트 미리보기 & 다듬기

GA 이후 다듬기 릴리즈: advisory 라우팅 힌트가 정식 읽기 전용 명령이 되고, 친화적
CLI 출력이 `run` 밖으로 확대되며, v1.2.0 기능이 완전히 문서화되고, 녹화 준비된
데모 시나리오가 들어간다. 하드 제약은 그대로: local-first, 결정론적, subprocess
전용, confirmation-first, 데몬 없음.

## 추가

- **`relay-baton route "<task>" [--json]`** — advisory 라우팅 힌트의 읽기 전용
  미리보기. `run`과 동일하게 체인을 결정한 뒤(플래그 > work-item 할당 > 프로젝트 >
  config), registry `strengths` 태그가 이 작업에 대해 순서를 어떻게 제안하는지
  agent별 매칭 키워드와 함께 보여준다. agent를 실행하지 않고 세션 상태도 쓰지
  않는다.
- **데모 시나리오** — `scripts/demo/demo.sh` + `scripts/demo/fake-agent.mjs`:
  fake agent로 fallback → compact handoff → 이어받기 흐름을 결정적으로 재현
  (실제 codex/claude 실행 없음, quota 소모 없음).
  `asciinema rec -c "bash scripts/demo/demo.sh" demo.cast` 로 녹화.

## 개선

- **친화적 출력 확대** — v1.2.0의 `ui` 스타일(✓ / ✗ / ▲ + "다음에 할 일" 힌트)이
  `doctor`, `init`, `status`, `login`, `handoff`까지 적용. `doctor`/`login`은
  기존에 ANSI를 하드코딩해 `NO_COLOR`/비-TTY를 무시했는데 이제 올바르게 plain
  텍스트로 강등된다.
- **`doctor`가 트리거 상태 표시** — 선택 설정 `handoffTriggers`가 구성됐는지 Core
  info 라인으로 보여줘 v1.2.0 기능을 발견할 수 있게 한다.
- **문서 완결** — `--handoff-now`, `handoffTriggers` 설정 블록(예시 JSON 포함),
  라우팅 힌트, `route`가 `docs/COMMANDS.md`(EN+KO), 가이드(EN+KO), README 설정
  섹션에 문서화됐다.

## 호환성

- breaking change 없음; config/아티팩트 스키마 변경 없음. `route`는 순수 추가.
