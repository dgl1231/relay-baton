# v1.2.0 — 더 똑똑한 릴레이 & 친화적인 UI

> 참고: v1.1.x 태그는 GA 이전 "Distributable" 라인이 사용했기 때문에, GA 이후 첫
> 기능 릴리즈는 v1.2.0으로 나간다.

GA 이후 첫 기능 릴리즈로 v2.8 "Smarter relay"와 CLI/데스크톱 UX 개선을 담았다.
하드 제약은 그대로: local-first, 결정론적, subprocess 전용, confirmation-first,
데몬 없음.

## 추가

- **핸드오프 트리거 확장 (opt-in).** 새 선택 설정 `handoffTriggers`
  (`budgetRatio`, `changedFiles`, `usageTokensProxy`)로 fallback 에러 패턴 없이도
  바통 터치를 *제안*한다. 임계치 도달 시 y/N 확인(또는 `--yes`); 설정이 없으면
  기존처럼 에러 패턴 감지만 동작한다. Core: `HandoffTriggerPolicy`.
- **수동 핸드오프 트리거.** `relay-baton run --handoff-now`는 fallback 신호를
  기다리지 않고 각 hop 후 다음 에이전트로 릴레이한다(플래그 자체가 명시적 동의).
- **advisory 라우팅 힌트.** 레지스트리 에이전트에 `strengths` 키워드 태그 추가;
  `suggestChain`이 작업 문자열에 맞는 체인 순서를 제안하고, 다를 때만 `run`이 한
  줄 힌트를 출력한다. 표시 전용 — 명시적 `--chain`/`--primary`가 항상 우선.

## 개선

- **친화적인 CLI 출력.** 의존성 없는 `ui` 헬퍼(✓ / ✗ / ▲ / → + "다음에 할 일"
  힌트) 도입, `run` 출력을 hop 제목과 명확한 게이트 실패 표시로 재구성. 파이프
  출력이나 `NO_COLOR`에서는 색상이 자동 비활성화된다.
- **데스크톱 웜 리스타일.** Tauri 웹뷰에 따뜻한 팔레트(크림 라이트 테마, 웜 다크
  테마, 테라코타 액센트), 시스템 산세리프, 부드러운 모서리/그림자, 메시지 카드형
  대화 이벤트 적용. 표시 전용 — 웹뷰는 여전히 CLI sidecar만 호출한다.

## 수정

- stdin이 TTY가 아닐 때(CI/파이프) `run` 확인 프롬프트가 무한 대기하던 문제 —
  이제 자동 거절하며 `--yes` 안내를 출력한다.
- Windows CI: worktree 테스트 경로 비교가 8.3 단축 경로를 확장하도록 수정.

## 호환성

- breaking change 없음. 새 설정 키 `handoffTriggers`는 선택이며 검증된다.
  아티팩트 스키마 변경 없음.
