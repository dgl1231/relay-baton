# v1.1.0 — 배포 가능 (Distributable)

이제 relay-baton은 소스에서 빌드해야만 쓰는 도구가 아니라 **내려받아 바로 실행**하는
도구다. CLI는 여전히 엔진이고, 새로 추가된 표면은 그 위의 얇은 껍데기다. 모든 핵심
제약은 그대로다(직접 API 호출 없음, key 저장 없음, 자동 commit/push/PR 없음,
deterministic compaction만).

## 핵심

- **단일 실행파일.** `linux-x64`, `macos-arm64`, `windows-x64`용 단일 파일 바이너리를
  Node SEA(Single Executable Application)로 빌드한다. 실행에 Node 설치가 필요 없다.
- **자동 릴리즈 파이프라인.** `v*` 태그를 push하면 `.github/workflows/release.yml`가
  OS별 바이너리를 빌드해 GitHub Release에 첨부한다. 기본 `GITHUB_TOKEN`만 쓰며 npm
  publish나 추가 secret이 없다.
- **README 다운로드 링크.** OS에 맞는 바이너리를 바로 받을 수 있는 "latest release"
  링크를 추가했다.
- **Tauri 데스크톱 셸(scaffold).** 새 `desktop/` 앱이 CLI를 Tauri **sidecar**로 감싼다.
  webview가 `relay-baton status/budget --json`을 호출하며 로직을 중복하지 않는다.
  pnpm workspace 밖에 있어 TypeScript 빌드/테스트 CI에 영향이 없다. 완전한 GUI는
  v1.2에서 나온다.

## 동작 방식

릴리즈 job은 `pnpm build` 후 컴파일된 CLI(및 workspace 의존성)를 `esbuild`로 하나의
CommonJS 파일로 번들하고, [`bin/sea-config.json`](../../bin/sea-config.json)으로 SEA
blob을 만든 뒤, 호스트 `node` 바이너리를 복사해 `postject`로 blob을 주입한다.
`esbuild`와 `postject`는 `npx`로 실행하므로 저장소 lockfile은 바뀌지 않고 build/test
워크플로는 그대로 통과한다.

## 받기

[latest release](https://github.com/dgl1231/relay-baton/releases/latest)에서
바이너리를 받아 실행한다:

```bash
# macOS / Linux
chmod +x relay-baton-macos-arm64
./relay-baton-macos-arm64 --version
```

```powershell
# Windows
.\relay-baton-windows-x64.exe --version
```
