# v1.6.0 — 현대적인 Windows 설치 관리자

Windows 데스크톱 앱이 이제 옛날 MSI 마법사 대신 **브랜드 디자인의 NSIS
설치 관리자**로 배포된다.

## 무엇이 바뀌었나

- **`…_en-US.msi` → `…-setup.exe` (NSIS).** 앱과 통일된 웜 다크 환영
  패널의 현대적 설치 화면 — 회전한 주황 다이아몬드 마크, `relay-baton`
  워드마크, `codex → claude handoff` 태그라인.
- **per-user 설치, UAC 프롬프트 없음.** VS Code나 Discord처럼 사용자
  프로필에 설치된다 — "이 앱이 변경하도록 허용" 대화상자도, 관리자 권한도
  필요 없다.

## MSI 설치본에서 업그레이드

NSIS 빌드는 별개의 설치 형식이다. 이전 버전을 MSI로 설치했다면 **설정 →
앱**(또는 기존 "Uninstall relay-baton" 바로가기)에서 한 번 제거한 뒤 새
`…-setup.exe`를 실행하면 된다. 이후 업데이트는 NSIS 설치본으로 이어진다.

## 영향 없음

- **CLI 사용자**(npm / Homebrew / Scoop / Winget) — 변화 없음. 이 채널들은
  데스크톱 설치본과 무관한 `relay-baton` 단독 실행파일을 설치한다.
- macOS `.dmg`와 Linux `.AppImage` — 변화 없음.
- CLI/앱 동작 변화 없음; 버전은 lockstep으로 범프.
