# v1.6.1 — 원클릭 Windows 설치

v1.6.0 NSIS 설치 관리자의 후속: Windows 설치가 이제 마법사를 거치지 않고
**원클릭**으로 끝난다.

## 무엇이 바뀌었나

- **마법사 페이지 제거.** 환영 화면과 "설치 위치 선택" 단계가 사라졌다.
  `…-setup.exe`를 더블클릭하면 기본 per-user 위치에 바로 설치되고 브랜드
  완료 화면이 뜬다 — Discord·VS Code처럼 틀이 앞을 가로막지 않는 현대적인
  설치 방식.
- 웜 다크 브랜드 아트워크(주황 다이아몬드 + `relay-baton` 워드마크)는 완료
  화면과 설치 진행 헤더에 그대로 나온다.
- 여전히 **per-user, UAC 프롬프트 없음**(v1.6.0부터).

## 내부

- 커스텀 NSIS 템플릿(`desktop/src-tauri/installer/installer.nsi`, Tauri
  공식 템플릿 기반·버전 일치)이 템플릿에 이미 있는 `Skip` 훅으로 환영/디렉터리
  페이지를 건너뛴다. 업그레이드 시에는 재설치 확인 화면이 그대로 표시된다.

## 영향 없음

- CLI 채널(npm / Homebrew / Scoop / Winget), macOS `.dmg`, Linux `.AppImage`
  — 변화 없음. CLI/앱 동작 변화 없음; 버전은 lockstep으로 범프.
