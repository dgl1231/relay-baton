# v2.0.0-alpha.4 — git-baseline을 버전드 스키마 계약에 편입

v2.0 스키마 작업을 확장해 `git-baseline.json`을 1급 버전드 아티팩트로 만든다.
버전 bump 없음, breaking change 없음 — 커버리지만 추가.

## 추가

- `git-baseline.json`이 버전드 스키마 레지스트리(`ARTIFACT_SCHEMA_VERSIONS`)에
  편입됨. 새 baseline은 `schemaVersion`과 함께 작성되며, `relay-baton migrate` /
  `doctor --deep`가 다른 버전드 아티팩트처럼 보고/정규화한다.

## 변경

- `GitService.baselineSnapshot()`이 `schemaVersion`을 stamp한다. `GitBaseline`은
  optional `schemaVersion`을 가진다(없으면 legacy v1).

## 마이그레이션

- v2.0 이전의 `git-baseline.json`(`schemaVersion` 없음)은 `legacy`로 감지되어
  `relay-baton migrate --apply`로 정규화된다(먼저 `.bak` 백업). 멱등적.

## v2.0 현황

버전드 계약 커버리지가 이제 `session.json`, `checkpoints.jsonl`,
`git-baseline.json`, archive/bundle manifest를 포함한다. 남음: conversation
이벤트를 레지스트리에 편입; 아티팩트별 버전 bump는 breaking change가 필요할 때.
