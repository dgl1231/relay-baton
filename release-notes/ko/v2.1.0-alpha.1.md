# v2.1.0-alpha.1 — handoff 전 redaction

v2.1 "secret safety" 두 번째 항목: secret이 다음 agent로 가지 않게 막는다.

## 추가

- **Redaction Gate.** `buildHandoff()`가 생성된 handoff(다음 agent가 읽는 바로 그
  내용)를 `RedactionScanner`로 스캔한다. 이후 `run`과 `handoff`는 **high-severity**
  finding(secret, API key, private key)이 있으면 `--force` 없이는 다음 agent 실행을
  차단한다. medium finding(절대 home 경로, 과대 콘텐츠)은 경고만.

## 이유

redaction이 이전에는 handoff *번들* export 때만 돌았다. 이제 실제 continuation
경로에서도 돌아서, repo 상태에 새어든 키가 fallback agent에게 조용히 넘어가지
않는다.

## 비고

- 결정적, 모델 호출 없음. handoff 파일은 여전히 작성되며, gate는 다음 agent 실행
  여부만 통제한다.

## v2.1 다음 항목

- secret 유출 회귀 스캔 + `--allow-api-key-env` audit 이벤트.
