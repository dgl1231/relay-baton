# v1.3.0-alpha.0 — Desktop 대화창 + project별 session

이번 alpha는 Agent Room 흐름을 desktop 앱 안으로 가져온다. 다만 안전 모델은
그대로 유지한다. GUI는 여전히 bundled CLI sidecar만 호출하고, agent 실행 계열
작업은 confirm-first다.

## 변경사항

- desktop timeline 아래에 Agent Room composer를 추가했다.
- 일반 텍스트 메시지는 active project의 `.ai-session/conversation.jsonl`에
  저장된다.
- slash command echo도 check 실행 전에 기록되어 timeline이 project별로
  replay 가능하게 유지된다.
- desktop/session 연동용 CLI 표면으로
  `relay-baton conversation append <text> --json`을 추가했다.
- conversation panel에 active project와 session state를 표시한다.
- 새 desktop chrome은 English, Korean, Japanese, Simplified Chinese i18n을
  유지한다.

## 안전 모델

- `/status`, `/budget`, `/review`, `/diagnose`, `/replay`는 sidecar를 통한
  check/read 작업이다.
- `/plan`, `/execute`, `/handoff`는 기존 preview/confirm dialog를 연다.
  composer가 agent를 자동 실행하지 않는다.
- 직접 LLM API 호출, API key 저장, daemon, auto commit, auto push, auto PR은
  추가하지 않았다.

## 호환성

- `project add`는 계속 non-git directory 등록을 허용한다. 실제 diff/handoff가
  필요한 git 기반 명령은 실행 시 git repository가 필요하다.
- `conversation append`는 초기화된 `.ai-session`이 필요하다. 먼저
  `relay-baton init` 또는 desktop의 "Init session" 버튼을 사용한다.
- Tauri 앱 버전은 installer 호환을 위해 plain `1.3.0`으로 둔다. prerelease
  식별은 git tag/release name에서 한다.
