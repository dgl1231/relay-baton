# v2.0.0-alpha.1 — 스키마 마이그레이터 (apply 경로)

v2.0 스키마 감지(`v2.0.0-alpha.0`) 위에 안전한 opt-in 마이그레이션 적용 경로를
추가합니다. 결정적·확인 우선·모델 호출 없음.

## 추가

- **스키마 마이그레이터** — `relay-baton migrate --apply [--dry-run]`이
  `.ai-session` 아티팩트에 안전한 마이그레이션을 적용합니다. 현재 마이그레이션은
  **legacy 정규화**: `schemaVersion` 필드가 없는 구버전 아티팩트에 현재 버전을
  stamp합니다.
- **안전 모델** — apply는 opt-in(`--apply`)이며 기본 동작과 `--check`는 읽기
  전용입니다. 변경마다 먼저 timestamp `.bak.<ts>` 백업을 쓰고, `--apply --dry-run`은
  계획만 미리 보며, 멱등적입니다.
- **전방 호환** — 버전 간 업그레이드는 보고되지만 해당 migrator가 등록될 때(첫 실제
  스키마 버전 bump)까지 skip됩니다.

## 제약

- 결정적, 모델 호출 없음.
- 조용한 변경 없음: apply는 명시적이며 항상 먼저 백업합니다.

## v2.0 다음 항목

- breaking change가 필요할 때 아티팩트별 schema v2 bump.
- i18n parity를 갖춘 안정적인 데스크톱 계약.
- installer/update 스토리 확정, 공개 문서 패스, 하드 제약 재확인.
