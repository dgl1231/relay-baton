# v1.5.0-alpha.1 — 배포 정리와 데스크톱 updater

이 alpha는 v1.5 git tracking 라인은 유지하면서, v1.4 배포 작업에서 남아 있던
desktop updater 항목을 마무리합니다.

## 추가

- 데스크톱 대시보드에 opt-in/manual 업데이트 확인 카드 추가.
- 확인 우선 방식의 데스크톱 업데이트를 위해 Tauri updater/process 플러그인 연결.
- updater signing secret이 있을 때 signed updater artifact와 `latest.json`을
  생성/업로드하는 릴리즈 워크플로우 지원.
- signed desktop updater artifact용 `latest.json` 생성 스크립트 추가.

## 변경

- `docs/ROADMAP.md`, `docs/RELEASE.md`, `docs/HANDOFF.md`,
  `docs/TASK-v1.4-distribution.md`에 v1.4 deferred updater 완료와 v1.5 git
  tracking shipped 상태를 반영했습니다.
- `docs/ROADMAP.md`에 v1.6부터 v2.0까지의 로드맵을 기록했습니다.

## 제약

- 업데이트 확인은 기본으로 꺼져 있습니다.
- 데스크톱 앱은 조용히 업데이트를 확인하지 않습니다. 사용자가 opt-in을 켜고
  **업데이트 확인**을 눌러야 합니다.
- 설치 전에도 확인을 한 번 더 받습니다.
- updater artifact는 Tauri updater signing secret이 있을 때만 생성됩니다.
  secret이 없어도 기존 unsigned installer 릴리즈는 계속 성공합니다.
