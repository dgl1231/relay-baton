# v1.2.0-alpha.0 — Desktop GUI (Phase A + B 미리보기)

v1.2 데스크탑 라인의 첫 **프리릴리스**. 새 데스크탑 빌드 파이프라인을 end-to-end로
검증하고, 초기 읽기 전용 대시보드를 포함한다. CLI 동작은 변경 없음. 모든 데스크탑
표면은 CLI 위의 얇은 shell이다.

> ⚠️ 프리릴리스. 데스크탑 인스톨러는 **미서명(Windows) / ad-hoc 서명(macOS)**이라
> SmartScreen / Gatekeeper 경고가 뜰 수 있다. GUI는 읽기 전용이며 아직 agent를
> 실행하지 못한다(Phase C 예정).

## 추가

- **데스크탑 릴리스 파이프라인** — `release.yml`에 `build-desktop` 매트릭스 잡
  추가(SEA 바이너리 이후): CLI를 Tauri sidecar로 스테이징 → 아이콘 생성 →
  `tauri build` → `.dmg`/`.msi`/`.AppImage`를 Release에 첨부. 이 태그가 첫 실제
  실행이다.
- **결정적 데스크탑 아이콘** — `npm run gen-icon-source`가 이미지 라이브러리 없이
  커밋된 `icon-source.png`를 생성하고, `npm run icon`이 CI에서 OS별 세트를 파생.
- **sidecar 스테이징** — `npm run stage-sidecar`가 Release 아티팩트/로컬 SEA
  바이너리를 Tauri target-triple 이름으로 `desktop/src-tauri/binaries/`에 매핑.
- **읽기 전용 대시보드**(`desktop/ui/index.html`) — 프로젝트 스위처, status 패널,
  사용량 바가 있는 budget 패널, diet 셀렉터(표시 상태만), 읽기 전용 handoff
  프리뷰. 모든 값은 CLI sidecar를 통해 흐른다.
- **표시용 CLI 표면** — `project list --json`, `project current --json`,
  `handoff show [--file <name>] [--json]`(읽기 전용; `--file`은 `handoff history`
  목록의 이름만 허용 → path traversal 차단).

## 비고

- `desktop/package.json`이 `@tauri-apps/cli`를 고정해 전역 `cargo tauri` 없이도
  `npm run dev/build`가 동작. 단, 빌드에는 Rust 툴체인이 필요하다.
- 하드 제약 불변: webview는 비즈니스 로직 없음, `.ai-session/` 직접 접근 없음,
  자동 commit/push/PR 없음.
