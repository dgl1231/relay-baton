# relay-baton v1.0.0 릴리즈 노트

상태: **Released**

날짜: 2026-05

테마: **Stable Local Release** — 영속 계약을 동결하고, `.ai-session/` 아티팩트를
보장하고, 모든 명령을 문서화하고, Agent Room workflow를 안정화한다. 새 모델 동작
이나 새 외부 표면은 없다. 1.0을 안심하고 의존할 수 있게 만드는 내구성과 문서만
추가한다.

## 요약

v1.0은 relay-baton의 디스크 표면을 안정적 계약으로 만든다. config와 session
메타데이터 형태에 버전을 부여(`CONFIG_VERSION`, `SESSION_SCHEMA_VERSION`)하고
검증한다. 새 deterministic·읽기 전용 `validateArtifacts`가 `.ai-session/` 아래
모든 것의 형태를 점검하며 `doctor --deep`에 연결된다. 전체 CLI는
`docs/COMMANDS.md`(EN + KO)에 문서화되고, Agent Room 명령 세트는 읽기 전용
`/diagnose` 추가로 확정된다. 모든 것은 subprocess 전용, confirmation-first를
유지하며 자동 commit/push/PR이 없다.

## 추가

- **계약 동결** — `@relay-baton/shared`의 `CONFIG_VERSION = 1`,
  `SESSION_SCHEMA_VERSION = 1`. `validateConfig` / `validateSessionMeta`(및
  `normalizeConfig` / `normalizeSessionMeta`)가 검증하고 legacy 페이로드에 현재
  버전을 스탬프한다. 로더가 읽을 때 정규화한다.

- **아티팩트 안정성** — `validateArtifacts(repoRoot)`(core)가 `.ai-session/`의
  형태를 deterministic·읽기 전용으로 점검한다: `session.json`(파싱 +
  `SessionMeta` 계약 충족), `context-budget.json`(유효 JSON, 빈 값 → 경고),
  `conversation.jsonl`(비어 있지 않은 모든 줄이 유효 JSON). markdown 아티팩트는
  존재만 확인. `docs/ARTIFACTS.md`에 문서화.

- **`doctor --deep` 계약 점검** — 기존 도구/registry/plan/handoff 진단과 함께
  config 계약(`validateConfig`)과 아티팩트별 형태 결과를 보고한다.

- **전체 명령 레퍼런스** — `docs/COMMANDS.md`(+ `docs/i18n/COMMANDS.ko.md`)가
  모든 top-level 명령, 옵션, 공통 project / diet / auth 규칙을 문서화한다.
  README에서 링크.

- **Room `/diagnose`** — `doctor --deep`(config + 아티팩트 검증)을 실행하는 읽기
  전용 room 명령. 모델 호출 없음, 확인 없음. Agent Room 명령 세트 확정: `/plan`,
  `/replan`, `/execute`, `/continue`, `/review`, `/diagnose`, `/handoff`,
  `/budget`, `/status`, `/replay`, `/help`, `/exit`.

## 변경

- CLI 버전을 `1.0.0`으로 상향(전체 workspace 패키지).
- `relay-baton.config.json`에 `configVersion`, `session.json`에 `schemaVersion`
  포함. 둘 다 자동 스탬프되며 이전 파일은 읽을 때 정규화된다.
- `docs/AGENT_ROOM.md`를 확정된 명령 표와 v1.0 상태로 갱신.

## 테스트

- `ContractSchema.test.ts` — config + session-meta 검증 및 버전 정규화.
- `ArtifactValidator.test.ts` — 정상 세션 통과, 파싱 불가/계약 위반
  `session.json` 실패, 빈 budget 경고, 손상된 `conversation.jsonl` 실패, 부재
  아티팩트/디렉터리는 ok 유지.
- `RoomEngine.test.ts` — `/diagnose`는 읽기 전용(확인 없음).
- `docs.test.ts` — `docs/ARTIFACTS.md`, EN+KO 명령 레퍼런스, 확정된 room 명령
  세트 존재 확인.

## 미포함 (여전히 보류 / 범위 밖)

- 데모 gif / 스크린샷, 문서화된 real-agent end-to-end 경로 — deterministic하게
  생성 불가, 보류.
- 비대화형 `run --until` 오케스트레이션, daemon / 장기 실행 프로토타입.
- semantic summarization, exact tokenizer, 자동 commit/push/PR — 영구 범위 밖.

## 업그레이드 노트

- 완전히 additive하고 하위 호환. 수동 마이그레이션 불필요: 기존
  `relay-baton.config.json`과 `.ai-session/session.json`은 읽을 때 현재 스키마
  버전으로 정규화된다. 새 검증기는 읽기 전용.

## 검증 명령

```bash
pnpm build
pnpm test
relay-baton doctor --deep   # config 계약 + 아티팩트 형태
relay-baton chat            # /help, 그다음 /diagnose(읽기 전용), /exit
relay-baton verify
```
