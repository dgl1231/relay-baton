# v1.4.0-alpha.1 — Distribution polish hotfix

This alpha keeps the v1.4 distribution polish scope and fixes the macOS release path discovered in `v1.4.0-alpha.0`.

## Fixed

- macOS desktop release builds no longer receive Apple signing environment variables unless all required Apple signing secrets are configured.
- When Apple signing secrets are absent, the release workflow uses the unsigned/ad-hoc desktop build path instead of trying to import an empty certificate.

## Included from v1.4.0-alpha.0

- One-line Linux/macOS and Windows CLI installers with SHA-256 verification.
- Release `SHA256SUMS` and best-effort CycloneDX SBOM generation.
- Starter Homebrew formula and Scoop manifest files.
- Optional Windows MSI signing hook for Azure Artifact Signing.
- Desktop agent preview switcher for Codex/Claude command previews.
